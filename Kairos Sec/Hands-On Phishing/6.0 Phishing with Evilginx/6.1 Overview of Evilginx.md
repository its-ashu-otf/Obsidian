# Overview of Evilginx

### Key Concepts

#### 1. **Man-in-the-Middle Phishing**

Evilginx functions as a _man-in-the-middle proxy_. Rather than serving a fake login page, it intercepts real authentication sessions between the victim and a legitimate web application. This allows for real-time credential and session token harvesting.

#### 2. **Phishing Proxy**

Evilginx acts as an invisible proxy between the user and a legitimate application (e.g., WordPress). The user interacts with the legitimate site through the attacker's controlled infrastructure, unaware of the interception.

#### 3. **Session Hijacking**

Unlike GoPhish, which typically captures only usernames and passwords, Evilginx is capable of extracting **session tokens**. This allows an attacker to hijack authenticated sessions — a critical method for bypassing two-factor authentication (2FA).

#### 4. **Phishlets**

Phishlets are YAML-based configuration files that define how Evilginx behaves with target applications. They dictate what to proxy, what data to capture, and how to handle specific web services. This lab series will include hands-on creation of custom fishlets.

#### 5. **Stealth and Realism**

Due to its proxy-based nature, Evilginx presents the _actual target application_ to the victim, making it more realistic and stealthy. The only clues a user may detect are discrepancies in domain names or SSL certificate warnings, if any.

#### 6. **Targeted Phishing, Not Campaigns**

Unlike GoPhish, Evilginx does **not support campaign management**. It is best used in red team scenarios targeting high-value individuals (e.g., executives or engineers) via **spear phishing**. URLs (called _lures_) are sent manually.

#### 7. **No Campaign Dashboard**

There’s no user-friendly interface for batch operations or analytics. The tool is intended for precision over scale, aligning with red team goals rather than mass phishing simulations.

#### 8. **Future Expansion (GoPhish Integration)**

There is a new release of Evilginx that aim to combine its session hijacking capabilities with the campaign functionality of GoPhish. While not covered in this section, the course will be updated in the future to explore these integrations.
