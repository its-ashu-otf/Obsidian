# Installing and Configuring Evilginx

### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-step-by-step-instructions)Step-by-Step Instructions

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-1-log-into-your-droplet-and-domain-registrar)1. **Log into Your Droplet and Domain Registrar**

- SSH into your DigitalOcean droplet:

```
ssh root@[Your IP Address]
```

- Log into your Namecheap account in your browser. You’ll need to update DNS records shortly.

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-2-create-a-working-directory)2. **Create a Working Directory**

```bash
mkdir evilginx && cd evilginx
```

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-3-download-the-latest-evilginx2-release)3. **Download the Latest Evilginx2 Release**

```bash
wget [Evilginx Release URL]
```

Example:

```bash
wget [https://github.com/kgretzky/evilginx2/releases/download/v3.3.0/evilginx-v3.3.0-linux-64bit.zip](https://github.com/kgretzky/evilginx2/releases/download/v3.3.0/evilginx-v3.3.0-linux-64bit.zip)
```

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-4-extract-and-prepare-the-binary)4. **Extract and Prepare the Binary**

```bash
unzip evilginx-v3.3.0-linux-64bit.zip && chmod +x evilginx
```

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-5-review-the-file-structure)5. **Review the File Structure**

```
ls
```

You should see:

- `evilginx` (binary)
- `fishlets/` (folder)
- `redirectors/` (advanced use — not covered in this course)

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-6-check-firewall-rules)6. **Check Firewall Rules**

- In DigitalOcean dashboard:
    - Navigate to your Droplet → **Networking**
    - Ensure ports **80** (HTTP) and **443** (HTTPS) are open
    - If you previously set these up for GoPhish, no further changes are needed

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-7-launch-evilginx2)7. **Launch Evilginx2**

```
./evilginx
```

> If successful, you’ll be dropped into the Evilginx CLI.

---

#### [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/62-installing-and-configuring-evilginx#user-content-8-configure-domain-and-ip)8. **Configure Domain and IP**

Within the Evilginx shell:

config domain [Your Domain] config ipv4 external [Your Digital Ocean IP Address]

Example:

config domain hacksmarter-manufacturing.cam config ipv4 external 147.182.215.174
