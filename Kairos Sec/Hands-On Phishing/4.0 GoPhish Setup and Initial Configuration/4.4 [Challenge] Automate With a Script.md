## Objective

The goal of this challenge is to take everything you learned in this module—from updating a server and downloading GoPhish to configuring DNS and launching the admin portal—and automate the process with a custom script.

This lab is not required to complete the course, but it is strongly encouraged as an advanced challenge for those looking to strengthen their skills in scripting, automation, and DevSecOps practices.

---

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/44-challenge-automate-with-a-script#user-content-challenge-description)Challenge Description

Create a script that automates the full GoPhish deployment process demonstrated in the course. This includes:

1. System preparation (update, upgrade, install dependencies)
2. Downloading and extracting the GoPhish binary
3. Modifying the `config.json` with correct settings
4. Generating and applying SSL certificates using Certbot
5. Launching the GoPhish binary

> Advanced Option: Integrate dynamic DNS record creation using the Namecheap API.

---

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/44-challenge-automate-with-a-script#user-content-scripting-requirements)Scripting Requirements

Your script should ideally do the following:

**Update and prepare the system**

- Run system updates
- Install required packages (`unzip`, `certbot`)

**Download and configure GoPhish**

- Retrieve the latest GoPhish release
- Unzip into a dedicated directory

**Modify the** `**config.json**` **with:**

- `listen_url` set to `0.0.0.0:3333`
- Certbot-generated paths for `cert_path` and `key_path`

**SSL Certificate Automation (Manual or API-based)**

- Use Certbot with `--manual --preferred-challenges dns` or, for a more advanced version, automate DNS TXT record creation via the Namecheap API

**Launch GoPhish**

- Start the GoPhish binary and capture the temporary credentials
- Optionally log the output to a text file

- **Bash**: Shell scripting for basic automation.
- **Python**: Preferred for more advanced automation and API integration.
    - Libraries: `requests`, `subprocess`, `json`, `os`, etc.
- **Namecheap API**: To programmatically update DNS records.
