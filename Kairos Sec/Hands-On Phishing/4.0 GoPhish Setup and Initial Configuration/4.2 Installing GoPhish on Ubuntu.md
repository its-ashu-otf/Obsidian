## Objective

The purpose of this lab is to introduce GoPhish, an open-source phishing simulation platform, and guide you through the environment setup required before installation. This lab will also highlight how GoPhish compares to commercial platforms such as KnowBe4.

By the end of this lab, you will:

- Understand what GoPhish is and what it is used for.
- Recognize its core features and use cases.
- Prepare a Linux-based server environment for installation.

---

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/41-overview-of-gophish#user-content-background)Background

GoPhish is a powerful, free, and open-source phishing simulation tool. It is commonly used in penetration testing and red team operations to simulate phishing campaigns and measure user susceptibility. Compared to commercial tools like KnowBe4, GoPhish offers many similar capabilities without licensing costs or vendor lock-in.

Key characteristics:

- Hosted on GitHub and actively maintained.
- Widely used in security awareness testing and red team engagements.
- Enables full campaign management, including target groups, email templates, and result tracking.

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/41-overview-of-gophish#user-content-lab-environment-requirements)Lab Environment Requirements

The recommended environment is a cloud-based virtual machine, such as a DigitalOcean Droplet.

Minimum setup:

- Ubuntu 22.04 server with sudo access
- Public IP address
- SSH access to the server
- Optional: Domain name for SSL configuration

> Note: This guide will only cover installation on Ubuntu. Installation on macOS or Windows requires separate steps and is not supported in this lab.
