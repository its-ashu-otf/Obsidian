#### Analyzing SSH Authentication (Port 22)

Since only SSH is open, it's crucial to check the authentication method, as password-based authentication is something we may be able to exploit.

- Command to Check Authentication Type:


### Deeper Enumeration (UDP)
The initial TCP scan only showing port 22 suggests a critical service may be hidden on UDP ports or less common TCP ports. The instructor performs a targeted UDP scan on the top ports.

Command:
```bash
sudo nmap -sU --top-ports 10 banksmarter.hsm -Pn
```

- `-sU`: Specifies a UDP scan. UDP scans are generally slower and often show ports as open|filtered.
- `--top-ports 10`: Scans the top 10 most common UDP ports (Default is 1000).
- `-Pn`: Treats all hosts as online (skips host discovery).

- Results:

### Phase 3: Enumerating SNMP (Port 161)
SNMP is a protocol used to monitor network devices, and misconfigured instances often use default, weak community strings like public or private, which allow enumeration of system information.

##### Using snmpwalk
**snmpwalk** is a tool that uses `SNMP GETNEXT` requests to query an `SNMP` agent for a tree of information, effectively enumerating the device's Management Information Base (`MIB`).

#### Command:
```bash
snmpwalk -v2c -c public banksmarter.hsm
```

	-v2c: Specifies SNMP version 2c.
	-c public: Specifies the community string, 'public' being a common default read-only string.
