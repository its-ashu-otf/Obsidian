To master SQL injection, you have to think like a **Database Administrator (DBA)**. Databases are essentially organized filing cabinets, and SQL (**Structured Query Language**) is the set of instructions we use to talk to the "clerk" running that cabinet.

In this lab, you are working with **SQLite**. Unlike other databases, SQLite stores its entire structure (metadata) in a special table called `sqlite_master`.

---

## Mission 0: Information Gathering

Before you can change data, you need to know what the tables are named and what columns they have.

### The Syntax: `SELECT`

The `SELECT` statement is used to fetch data.

* `*` means "everything."
* `FROM` specifies the table.

**Command:**

```sql
SELECT name, sql FROM sqlite_master WHERE type='table';

```

**How it works:**
This asks the database: *"Show me the name and the original code used to create every table you have."* This will likely reveal two tables: one for **Products** and one for **Employees**.

---

## Mission 1: Find Product with 1337 Stock

Now that you know the table name (let's assume it's `products`), you need to filter results.

### The Syntax: `WHERE`

The `WHERE` clause acts as a filter to narrow down your search.

**Command:**

```sql
SELECT * FROM products WHERE stock = 1337;

```

**How it works:**
The database scans the `stock` column for every row. If the value matches `1337`, it returns that row. In a CTF, the "Product Name" or "Description" here is often your first flag fragment.

---

## Mission 2: Move 'Alice Smith' to 'Cybersecurity'

You aren't just reading data now; you are changing it.

### The Syntax: `UPDATE` & `SET`

* `UPDATE` tells the DB which table to modify.
* `SET` defines the new value.
* **Crucial:** Always use a `WHERE` clause, or you will change *everyone's* department to Cybersecurity!

**Command:**

```sql
UPDATE employees SET department = 'Cybersecurity' WHERE name = 'Alice Smith';

```

**How it works:**
The database finds the specific row where the name is 'Alice Smith' and overwrites the old department value with the new one.

---

## Mission 3: Add New Employee 'Hacker'

To add data, you create a whole new row.

### The Syntax: `INSERT INTO` & `VALUES`

* `INSERT INTO` specifies the table and columns.
* `VALUES` provides the data for those columns.

**Command:**

```sql
INSERT INTO employees (name, department, Salary) VALUES ('Hacker', 'Cybersecurity', '5200');
```

**How it works:**
This creates a brand-new entry at the end of the table. You must match the order of the columns defined in the table schema.

---

## Mission 4: Fire (Delete) 'Bob Jones'

The final administrative task is removing a record entirely.

### The Syntax: `DELETE`

* `DELETE FROM` identifies the table.
* `WHERE` identifies the specific record.

**Command:**

```sql
DELETE FROM employees WHERE name = 'Bob Jones';
```

**How it works:**
The database locates the row for 'Bob Jones' and deletes it from the disk. **Warning:** In the real world, `DELETE` without a `WHERE` clause wipes the entire table.

### Why this matters for SQL Injection:

When you perform a SQL Injection, you are "injecting" these exact commands into a website's input field. If a website asks for your username and you type `' OR 1=1 --`, you are actually manipulating the `WHERE` clause to bypass security.
