### 🔍 **Port Scanning & Enumeration with Nmap**

#### ✅ **What is Nmap?**

- **Nmap (Network Mapper)** is a **free, open-source** tool used for:
    
    - **Host discovery**
        
    - **Port scanning**
        
    - **Service and version detection**
        
    - **OS fingerprinting**
        
    - **Scriptable interaction with services** (via NSE – Nmap Scripting Engine)
        

---

#### ⚙️ **Key Capabilities of Nmap**

|Capability|Description|
|---|---|
|**Host Discovery**|Detect live systems on a network (`-sn`, `-Pn`, `-PS`, `-PE`)|
|**Port Scanning**|Identify open TCP/UDP ports (`-sS`, `-sT`, `-sU`)|
|**Service Enumeration**|Discover services and versions (`-sV`)|
|**OS Detection**|Fingerprint the OS and device type (`-O`)|
|**Scripted Enumeration**|Use NSE for vulnerability detection, brute force, misconfig checks (`-sC`)|

---

#### 🧪 **Common Nmap Commands for Enumeration**

```bash
# 1. Basic port scan
nmap <target>

# 2. Scan with service detection
nmap -sV <target>

# 3. Scan with OS detection
nmap -O <target>

# 4. Scan with default scripts (NSE) + version
nmap -sC -sV <target>

# 5. Aggressive scan (includes OS, version, script, traceroute)
nmap -A <target>

# 6. Output results in all formats (XML, normal, grepable)
nmap -oA scan_results <target>
```

---

#### 📤 **Exporting for Metasploit (MSF Integration)**

You can export your Nmap scan results to **XML format** for importing into **Metasploit**:

```bash
nmap -sS -sV -O -oX scan.xml <target>
```

Then in Metasploit:

```bash
msfconsole
db_import scan.xml
```

This allows Metasploit to correlate the discovered services with known vulnerabilities for further exploitation.
