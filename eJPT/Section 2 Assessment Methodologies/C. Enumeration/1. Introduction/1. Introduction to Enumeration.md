# **Enumeration – The Next Step After Scanning**

Once you've identified live hosts and open ports during the **host discovery** and **port scanning** phases, the next critical step in the penetration testing process is **enumeration**.

#### 🔍 What is Enumeration?

Enumeration is the **active process of collecting detailed information** about systems, services, and resources on a network. It helps map out the internal workings of the target environment, providing data that can be used for deeper exploitation.

#### 🎯 Enumeration Goals:

- Discover **usernames**, **group names**, and **roles**
    
- Identify **network shares**, **file systems**, and **running services**
    
- Uncover **software versions**, **configurations**, and **potential misconfigurations**
    
- Enumerate **domain information** and **trust relationships** (in AD environments)
    
- Collect **service-specific information** from open ports
    

#### 📡 Active Interaction Required:

Enumeration generally involves **active connections** with the target systems. This distinguishes it from passive reconnaissance and makes it more detectable.

#### 📑 Commonly Targeted Protocols & Services:

These are often misconfigured or exposed in insecure ways:

- **SMB (NetBIOS, port 139/445)** – file sharing, user enumeration
    
- **SNMP (port 161)** – system details, configurations
    
- **LDAP (port 389/636)** – directory services, AD structure
    
- **FTP (port 21)** – anonymous login, file listings
    
- **RPC/NetBIOS (ports 135/139)** – shared resources and services
    
- **SMTP (port 25)** – user enumeration
    
- **HTTP/HTTPS (ports 80/443)** – web server directories, apps
    
- **SSH (port 22)** – banner grabbing, version info
    

#### 🧰 Enumeration Tools:

You'll learn to use tools like:

- `enum4linux`, `rpcclient`, `smbclient` – SMB and NetBIOS enumeration
    
- `nmap` scripts (`-sC`, `--script`) – service-specific enumeration
    
- `snmpwalk` – SNMP info gathering
    
- `ldapsearch` – LDAP enumeration
    
- `dirb`, `gobuster`, `nikto` – web server/file enumeration
