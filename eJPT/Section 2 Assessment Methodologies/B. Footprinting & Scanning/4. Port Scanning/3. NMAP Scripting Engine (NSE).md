# 🎯 What is the Nmap Scripting Engine (NSE)?

- NSE allows Nmap to **run custom scripts** **against targets** to automate **advanced reconnaissance, vulnerability detection, exploitation**, even **post-exploitation**!
    
- Think of it like this:
    
    > **Nmap + Lua scripts = A lightweight vulnerability scanner & exploitation toolkit built-in!**
    

✅ Scripts can do stuff like:

- Detect **vulnerabilities** (e.g., Heartbleed, SMBGhost, CVEs)
    
- **Brute-force** credentials
    
- **Enumerate** services (e.g., HTTP, SMB shares, FTP files)
    
- **Fingerprint** applications
    
- **Exploit** weak configurations
    

---

### **Default Script Scan in Nmap**

In Nmap, the **default script scan** uses the **default NSE scripts** that are designed to perform **safe** and **general-purpose** network discovery. These scripts are **non-intrusive** and are usually intended to gather information about the target without being too aggressive or causing issues like service crashes.

### 🎯 **What Does the Default Script Scan Do?**

When you run an Nmap scan with the **`-sC`** flag (which stands for **"script scan"**), Nmap will execute a set of **default scripts** that help in:

- **Service Version Detection**: Identifying versions of services running on open ports.
    
- **Basic Enumeration**: Gathering basic information about services (e.g., banner grabbing, HTTP title, FTP anonymous access, etc.).
    
- **Vulnerability Checking**: Running safe vulnerability checks to identify potential weaknesses.
    

These default scripts are part of **Nmap's default script set** located in `/usr/share/nmap/scripts/` (or equivalent on your OS).

---

### 🛠️ **How to Run a Default Script Scan**

The easiest way to perform a **default script scan** is by using the `-sC` flag in conjunction with your target IP address.

```bash
nmap -sC <target>
```

- This will run **safe and general-purpose** scripts like:
    
    - **Banner grabbing**
        
    - **HTTP title grabbing**
        
    - **Basic service enumeration** on commonly scanned ports
        
    - **SSL certificate checks** (on port 443)
        
    - **DNS resolution checks**
        
    - And more!

### 🧩 **What Scripts Are Included in the Default Script Set?**

Some common scripts executed in a **default scan** include:

- **http-title**: Grabs the title from an HTTP server.
    
- **ssl-cert**: Extracts SSL certificate information.
    
- **http-server-header**: Retrieves the `Server` HTTP header.
    
- **banner**: Attempts to grab banners from services.
    
- **dns-brute**: Performs DNS brute force for subdomain enumeration.
    
- **ftp-anon**: Checks if anonymous FTP login is allowed.
    
- **smb-os-discovery**: Discovers OS version and shares via SMB.
    
- **mysql-info**: Grabs MySQL service information.
    
- **http-methods**: Identifies HTTP methods allowed (e.g., GET, POST).
    
- **http-security-headers**: Checks for security headers like Content-Security-Policy, X-Frame-Options, etc.
    

---

### 🚀 **What Happens Internally During `-sC` Scan?**

When you use `-sC`:

1. **Port Scanning** happens first.
    
2. Nmap checks the **open ports** and applies the **default scripts** against them.
    
3. For each service discovered (like HTTP, FTP, SSH), the scripts are **designed to be non-intrusive** and collect useful information (like version numbers, banners, or SSL certificate details).
    
4. **Results are printed** in the standard Nmap output format.
    

---

### ⚡ **Advantages of Using `-sC`**

- **Quick and Safe**: Perfect for quick reconnaissance without overloading the target system.
    
- **No Risk of Overloading**: Default scripts are light and do not cause issues like crashing services.
    
- **Useful for Basic Enumeration**: Provides important insights into a system's configuration.
    
- **Ideal for Initial Scanning**: It gives you a decent amount of info about the services running without being intrusive.


---

### 🔥 **Combining `-sC` with Other Options**

You can also combine **`-sC`** with other Nmap flags to make your scan even more powerful:

1. **Adding Version Detection**:
    
    ```bash
    nmap -sC -sV 192.168.1.100
    ```
    
    This will run both **default scripts** and **service version detection**.
    
2. **Aggressive Scan**:
    
    ```bash
    nmap -A 192.168.1.100
    ```
    
    This will run **default scripts**, **service version detection**, and **OS detection**.
    

---

### 🧑‍💻 **Bonus: How to Customize or Add Specific Scripts**

If you want to run custom scripts or more specific ones, you can directly reference them:

```bash
nmap --script http-methods,ssl-cert 192.168.1.100
```

This runs just the **http-methods** and **ssl-cert** scripts.

### 🏁 **Summary**

- **`-sC`** runs a **default script scan**, executing a collection of safe and useful scripts.
    
- **Ideal for initial reconnaissance** and basic service enumeration.
    
- Provides **valuable information** like HTTP headers, SSL certs, FTP login types, and more.
    
- It’s a **safe**, **quick**, and **non-intrusive** scan.

# 🛠️ **How to Use NSE**

👉 Basic syntax:

```bash
nmap --script <script-name> <target>
```

👉 Example:

```bash
nmap --script ftp-anon 192.168.1.100
```

_(Scans FTP server for anonymous login.)_

---

# 🧩 **Types of NSE Scripts**

Scripts are grouped into **categories** based on what they do:

|Category|Purpose|
|:--|:--|
|auth|Authentication bypass, brute-force|
|vuln|Vulnerability detection (CVEs, bugs)|
|safe|Safe information gathering|
|intrusive|Potentially dangerous scripts|
|exploit|Active exploitation|
|discovery|Network discovery, enumeration|
|brute|Password guessing attacks|
|malware|Malware detection (e.g., Conficker scan)|
|dos|Denial-of-Service attack scripts|

---

# 🔥 **Where are NSE Scripts Stored?**

- Located in:
    
    ```
    /usr/share/nmap/scripts/
    ```
    
    _(Linux/Kali/ParrotOS)_  
    or
    
    ```
    C:\Program Files (x86)\Nmap\scripts\
    ```
    
    _(Windows)_
    
- They are written in **Lua programming language** (very lightweight and fast).
    

---

# 📈 **How to Find and List Scripts**

👉 List all available scripts:

```bash
nmap --script-help=all
```

👉 Get help for a specific script:

```bash
nmap --script-help=ftp-anon
```

(Shows script description, usage tips, and options.)

List all installed scripts locally in file system:

```bash
ls -al /usr/share/nmap/scripts 
```

# 🧪 **Real Practical NSE Examples**

### 1. **Detect Anonymous FTP Access**

```bash
nmap -p 21 --script ftp-anon 192.168.1.100
```

### 2. **Find SMB Shares (Windows network)**

```bash
nmap -p 445 --script smb-enum-shares 192.168.1.105
```

### 3. **Check for Heartbleed Vulnerability**

```bash
nmap --script ssl-heartbleed -p 443 192.168.1.150
```

### 4. **Brute-force HTTP Basic Auth**

```bash
nmap --script http-brute -p 80 192.168.1.120
```

# ⚡ **Running Multiple Scripts at Once**

👉 Run all scripts in a category:

```bash
nmap --script vuln 192.168.1.100
```

(_Runs all vulnerability-related scripts!_)

👉 Or combine manually:

```bash
nmap --script ftp-anon,http-title,http-headers 192.168.1.100
```

---

# 🏗️ **How Scripts are Executed (Internals)**

1. **Pre-Scan Phase** (like DNS resolution scripts)
    
2. **Port Scan Phase** (e.g., version detection enhancement)
    
3. **Service Scan Phase** (e.g., SMTP enumeration)
    
4. **Post-Scan Phase** (e.g., OS guessing, traceroute)
    

Different scripts are automatically triggered based on what phase is happening.

---

# 🛡️ **Important NSE Tips**

- Some scripts are **intrusive** or **dangerous** (might crash services) — know what you are running!
    
- Always use **safe scripts** during passive reconnaissance.
    
- You can **tune scripts** with arguments, like:
    

```bash
nmap --script ftp-brute --script-args userdb=myusers.txt,passdb=mypasswords.txt 192.168.1.100
```

- Update scripts with:
    

```bash
nmap --script-updatedb
```

(Refreshes the script database if you add new ones.)
