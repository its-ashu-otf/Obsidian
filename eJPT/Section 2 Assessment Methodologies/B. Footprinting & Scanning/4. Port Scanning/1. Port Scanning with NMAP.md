## Port Scanning with NMAP

Port scanning with **Nmap** is a fundamental technique in penetration testing to discover open ports and services on a target system. Here’s a breakdown of key concepts, commands, and usage examples to get you up to speed:

---

## 🔹 **What is Port Scanning?**

Port scanning is the process of sending packets to specific ports on a host and analyzing the responses to:

- Identify **open**, **closed**, or **filtered** ports
    
- Discover **services** and their **versions**
    
- Determine **operating systems** and **host configurations**

---

### 🔹 **Basic TCP Port Scans**

- **Default scan (TCP SYN if root, TCP connect otherwise):**
    
    ```bash
    nmap <target>
    ```
    
- **Specific ports:**
    
    ```bash
    nmap -p 22,80,443 <target>
    ```
    
- **Port range:**
    
    ```bash
    nmap -p 1-1000 <target>
    ```

---

### 🔹 **Scan Types**

- **TCP SYN scan (Stealth, default for root):**
    
    ```bash
    nmap -sS <target>
    ```
    
- **TCP Connect scan (default for non-root):**
    
    ```bash
    nmap -sT <target>
    ```
    
- **UDP scan:**
    
    ```bash
    nmap -sU <target>
    ```
    
- **TCP Null scan:**
    
    ```bash
    nmap -sN <target>
    ```
    
- **TCP FIN scan:**
    
    ```bash
    nmap -sF <target>
    ```
    
- **TCP Xmas scan:**
    
    ```bash
    nmap -sX <target>
    ```

---

### 🔹 **Aggressive/Fast Scanning Options**

- **Fast scan (top 100 ports):**
    
    ```bash
    nmap -F <target>
    ```
    
- **Scan top 1000 ports faster (lower timing delay):**
    
    ```bash
    nmap -T4 <target>
    ```
    
- **Aggressive timing (very fast, risk of detection):**
    
    ```bash
    nmap -T5 <target>
    ```
    
- **Disable DNS resolution (faster):**
    
    ```bash
    nmap -n <target>
    ```
    
- **Scan all 65535 ports:**
    
    ```bash
    nmap -p- <target>
    ```
    

---

### 🔹 **Combining Options (Example)**

- **Fast TCP SYN scan of top 1000 ports without DNS resolution:**
    
    ```bash
    nmap -sS -T4 -n <target>
    ```
    
- **UDP + TCP top ports quickly:**
    
    ```bash
    nmap -sS -sU -F -T4 -n <target>
    ```
