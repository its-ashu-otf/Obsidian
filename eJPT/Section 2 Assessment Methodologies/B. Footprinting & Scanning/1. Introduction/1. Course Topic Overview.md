### 🛰️ **Introduction to Network Mapping – Overview**

Network mapping is the process of identifying active devices, open ports, services, and operating systems on a network. It's the first phase in penetration testing and helps build a blueprint of the target environment.

---

### 🔌 **Networking Fundamentals**

- Basic understanding of how computers communicate using **IP addresses**, **MAC addresses**, **ports**, and **protocols** (TCP/UDP).
    
- Key concepts: **OSI model**, **IP addressing**, **subnetting**, and **routing**.
    
- Essential to understand how data travels and how devices interact.
    

---

### 🧭 **Host Discovery with Nmap**

- Goal: Find _live hosts_ on the network.
    
- Techniques:
    
    - ICMP Echo Request (`-PE`)
        
    - TCP SYN Ping (`-PS`)
        
    - ARP Scan (LAN only)
        
- Helps identify which IPs are **active and reachable**.
    

---

### 🔍 **Port Scanning with Nmap**

- Determines which **ports are open**, closed, or filtered on a target.
    
- Scan types:
    
    - SYN Scan (`-sS`) – stealthy and fast
        
    - TCP Connect Scan (`-sT`)
        
    - UDP Scan (`-sU`)
        
- Helps find _services_ running on each host.
    

---

### 🧠 **Host Fingerprinting with Nmap**

- Identifies OS and software versions of the target.
    
- Uses:
    
    - OS detection (`-O`)
        
    - Version detection (`-sV`)
        
- Helps tailor exploits or tools to specific systems.
    

---

### 📜 **Introduction to the Nmap Scripting Engine (NSE)**

- Adds automation and power to Nmap with scripts.
    
- Useful for:
    
    - Vulnerability scanning
        
    - Brute-force attacks
        
    - Service enumeration
        
- Run with `--script <script-name>`.
    

---

### 🔥 **Firewall Detection & Evasion with Nmap**

- Detect presence of **firewalls**, **IDS/IPS**, or packet filters.
    
- Evasion techniques:
    
    - Fragment packets (`-f`)
        
    - Decoy scan (`--decoy`)
        
    - Source port manipulation (`--source-port`)
        
- Helps understand security controls in place.
    

---

### ⏱️ **Nmap Scan Timing & Performance**

- Control scan speed using `-T0` (slow) to `-T5` (fast/aggressive).
    
- Balances **stealth** vs **speed**.
    
- Use lower timing for stealthy scans, higher for speed when detection is not a concern.
    

---

### 📄 **Nmap Output & Verbosity**

- Control how results are displayed.
    
- Options:
    
    - Verbose (`-v`, `-vv`)
        
    - Output formats: Normal (`-oN`), XML (`-oX`), Grepable (`-oG`), All (`-oA`)
        
- Useful for documentation and reporting.
    

---

### ✅ Quick Summary Notes

```
- Nmap is essential for host discovery, port scanning, and service enumeration.
- Use various scan types for stealth and information gathering.
- NSE adds flexibility with automated scripts.
- Adjust timing & evasion techniques for different environments.
- Output formats help in organizing and analyzing scan results.
```
