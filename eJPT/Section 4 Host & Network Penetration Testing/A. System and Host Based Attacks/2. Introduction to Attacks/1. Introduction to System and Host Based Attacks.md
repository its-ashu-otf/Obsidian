## 🔐 What Are System/Host-Based Attacks?

### 📌 Definition:

System/Host-based attacks are **targeted attacks on individual systems or devices**—such as **servers, workstations, or laptops**—that are running a specific **operating system (OS)** like **Windows** or **Linux**.

---

### 💡 Key Points:

- ✅ These attacks are **not limited to network services**—they target the host itself, often post-initial access.
    
- ✅ Typically come into play **after network access is achieved** (e.g., via phishing, exploitation, or credential access).
    
- ✅ Focus is on **exploiting OS-level vulnerabilities**, misconfigurations, and system-specific weaknesses.
    

---

### 🔎 Characteristics:

|Feature|Description|
|---|---|
|🎯 Target|Specific OS (Windows/Linux), services, or user misconfigurations|
|🧠 Knowledge Required|Deep understanding of OS internals, file systems, permissions, services|
|⚙️ Attack Vectors|Privilege escalation, file system manipulation, credential dumping, persistence|
|🔁 Timing|Generally **post-exploitation** (once a foothold is gained inside the network)|

---

### 🧨 Techniques Involved:

- **Exploiting misconfigured services or permissions**
    
- **Abusing vulnerable binaries (e.g., SUID/SGID on Linux)**
    
- **Dumping credentials from memory or disk**
    
- **Escalating privileges to SYSTEM/root**
    
- **Maintaining persistence on the host (e.g., startup scripts, registry edits)**
    

---

### 🧠 Why It Matters:

- Network access is **just the first step**—real damage and data access usually happen on the host.
    
- Host-based attacks are **often stealthier** and more **tailored**, bypassing network-layer defenses.
    
- Modern organizations typically **harden the perimeter**, but **internal systems are often neglected** or misconfigured.
