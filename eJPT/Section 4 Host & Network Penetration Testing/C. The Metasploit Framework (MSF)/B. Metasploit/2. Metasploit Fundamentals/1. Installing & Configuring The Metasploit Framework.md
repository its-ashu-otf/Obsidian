## 🔧 Installing the Metasploit Framework (on Kali Linux)

### ✅ **Why Kali?**

- Comes **pre-installed** with Metasploit and its dependencies
    
- Saves you time and headache—no need for manual setup
    
- Actively maintained for offensive security tools
    

---

## 🗃 The Metasploit Framework Database (`msfdb`)

### 🔹 What It Does:

- Stores: host scan data, loot, creds, session info, workspace separation
    
- Powers: the `db_nmap`, `hosts`, `services`, and `loot` commands
    
- **Backed by**: `PostgreSQL`
    

---

## 🪛 Installation & Configuration Steps

> **Step-by-step guide to update and prep Metasploit with DB integration**

---

### 🔹 1. **Update System & MSF**

Keep everything fresh:

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install metasploit-framework -y  # Just in case
```

---

### 🔹 2. **Start PostgreSQL Database**

Check and start PostgreSQL:

```bash
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

Confirm it’s running:

```bash
sudo systemctl status postgresql
```

---

### 🔹 3. **Initialize the Metasploit Database**

Initialize `msfdb` (if not already done):

```bash
sudo msfdb init
```

It will:

- Start PostgreSQL (if needed)
    
- Create the database
    
- Set up the required DB schema
    
- Connect it with Metasploit
    

You can also check DB status using:

```bash
msfconsole
msf6 > db_status
# Output: connected to msf
```

---

### 🔹 4. **Launch MSFconsole**

Once DB is set, launch MSF:

```bash
msfconsole
```

You're now inside the full Metasploit shell. Example:

```bash
msf6 > workspace -a test_env
msf6 > db_nmap -sV 192.168.1.1
```

---

## 🧠 Pro Tips

|Tip|Description|
|---|---|
|`msfupdate`|Use this to manually update modules and exploits|
|`db_nmap`|Lets you run Nmap inside MSF and import results directly|
|`loot`, `creds`, `hosts`, `services`|All these store data in the PostgreSQL DB for future ops|
|Back up `~/.msf4`|To preserve configs and DB when switching machines or VMs|
