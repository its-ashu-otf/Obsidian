## 🧰 Metasploit Interfaces & Tools

### 🔹 **MSFconsole (Metasploit Framework Console)**

![[Pasted image 20250615213714.png]]

- **Primary and most powerful interface** to interact with Metasploit.
    
- All-in-one **interactive console** giving access to all framework features.
    
- Supports:
    
    - Module loading and execution
        
    - Database integration
        
    - Session handling
        
    - Scripting (via `resource` scripts)
        
    - Automation with workflows


> **Usage:** `msfconsole`

---

### 🔸 **MSFcli (Metasploit Command Line Interface)**

- Used to **script and automate** Metasploit module usage via CLI.
    
- Allowed **input/output redirection** with other tools or scripts.
    
- **Discontinued in 2015** — functionality integrated into `msfconsole`.    

> ✅ _Use `msfconsole` + resource scripts for modern automation needs._

---

### 🖥️ **Metasploit Community Edition**

![[Pasted image 20250615213743.png]]

- **Web-based GUI** front-end to Metasploit Framework.
    
- Simplifies:
    
    - **Network scanning**
        
    - **Vulnerability identification**
        
    - **Basic exploitation tasks**
        
- Ideal for users less comfortable with the command line.

---

### 🎯 **Armitage**

![[Pasted image 20250615213807.png]]

- Free, **Java-based GUI** front-end for Metasploit.
    
- Focus on:
    
    - **Visual network mapping**
        
    - **Team collaboration**
        
    - **Exploit automation**
        
    - **Post-exploitation management**
        
- Still useful in training/lab environments, though not frequently updated.
