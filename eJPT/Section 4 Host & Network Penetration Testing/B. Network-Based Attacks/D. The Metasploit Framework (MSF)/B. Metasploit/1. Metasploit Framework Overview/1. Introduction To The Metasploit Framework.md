# 🔍 What is Metasploit Framework (MSF)?

![[Pasted image 20250615212526.png]]

Metasploit Framework is a **free, open-source penetration testing platform** used to:

- **Develop**, **test**, and **execute** exploits
    
- **Automate** tasks in the **penetration testing lifecycle**
    
- Simulate real-world attacks for **vulnerability assessment** and **defence testing**


---

### 🔧 **Key Features of MSF:**

|Feature|Explanation|
|---|---|
|🔗 **Modular Design**|Uses independent modules: exploits, payloads, encoders, listeners, etc. Each can be swapped or updated easily.|
|📦 **Large Exploit Database**|Thousands of **publicly known exploits** and auxiliary tools already included.|
|🛠 **Exploit Development Platform**|Can **write your own exploits** and test them within the framework.|
|🧪 **Testing Automation**|Automates scanning, exploitation, and post-exploitation tasks.|
|💻 **Scriptable with Meterpreter**|Advanced post-exploitation payload with features like keylogging, file transfer, privilege escalation, etc.|
|💡 **Community Driven**|Source code is on **GitHub** – regularly updated by contributors.|

---

### ⚙️ **Metasploit Modules Overview:**

|Module Type|Purpose|
|---|---|
|**Exploit**|Code used to take advantage of a vulnerability|
|**Payload**|Code executed on the target after exploitation|
|**Auxiliary**|For scanning, fuzzing, sniffing, etc. (non-exploitation tasks)|
|**Post**|Scripts to gather info or escalate privileges **after** successful exploitation|
|**Encoder**|Obfuscates payloads to **bypass AV**|
|**Nops**|Padding used to ensure **reliable payload delivery**|

### 🧠 Use Case Scenario:

1. **Recon**: Use auxiliary modules to scan target
    
2. **Exploit**: Select and launch a suitable exploit module
    
3. **Payload**: Choose payload (e.g., reverse shell or Meterpreter)
    
4. **Post-Exploitation**: Dump credentials, escalate privileges, maintain access
    
5. **Reporting**: Document everything for your final pentest report

---

### 🧰 Bonus Tips for Practical Usage:

- Start Metasploit: `msfconsole`
    
- Search modules: `search type:exploit name:apache`
    
- Use a module: `use exploit/windows/smb/ms17_010_eternalblue`
    
- Set options: `set RHOST 10.10.10.10`
    
- Launch attack: `exploit`

- **2003** – Developed by **HD Moore**
    
- **Originally written in Perl**
    
- **2007** – Rewritten in **Ruby**
    
- **2009** – Acquired by **Rapid7**
    
- **2019** – Release of **Metasploit 5.0**

## 🧠 Essential Terminology

- **Interface**  
    Methods of interacting with Metasploit (CLI, GUI, API).
    
- **Module**  
    Reusable components in Metasploit that perform specific tasks.  
    _Example:_ Exploit, payload, auxiliary, post, encoder, etc.
    
- **Vulnerability**  
    A flaw or weakness in a system that can be exploited.
    
- **Exploit**  
    A module/code that takes advantage of a vulnerability to gain access or run arbitrary code.
    
- **Payload**  
    The actual code delivered by an exploit to the target system.  
    _Objective:_ Execute commands, spawn shells, or create backdoors.
    
- **Listener**  
    A service (like `multi/handler`) that waits for a payload to connect back (e.g., reverse shell).
