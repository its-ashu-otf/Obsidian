## ⚙️ **Nmap Overview in Offensive Context**

Nmap isn’t just about open ports — when used right, it’s a **multi-purpose reconnaissance and enumeration powerhouse**:

### 🔍 Capabilities:

- Host discovery (ping sweeps, ARP)
    
- Port scanning (TCP/UDP)
    
- Service detection (`-sV`)
    
- OS detection (`-O`)
    
- Scriptable interaction (NSE engine)
    
- Output for tool chaining (like importing into MSF)
    

---

## 🔧 **Common Nmap Scan Examples**

### 1. **Basic Port Scan**

```bash
nmap 192.168.1.10
```

### 2. **Service & Version Detection**

```bash
nmap -sV 192.168.1.10
```

### 3. **OS Detection + Aggressive Scan**

```bash
nmap -A 192.168.1.10
```

### 4. **Scan Multiple Hosts/Subnet**

```bash
nmap 192.168.1.0/24
```

---

## 📥 **Output for MSF Importing**

### 1. **Generate XML Output**

```bash
nmap -sS -sV -O -oX scan_results.xml 192.168.1.0/24
```

### 2. **Import into Metasploit DB**

Start `msfconsole`, then:

```bash
db_import /path/to/scan_results.xml
```

✅ This will populate your current **workspace** with:

- Host IPs
    
- Open ports
    
- Detected services
    
- OS info (if available)
    

---

## 🚀 **Or... Use db_nmap Directly Inside MSF**

If you want to skip XML and go direct:

```bash
db_nmap -sS -sV -O 192.168.1.0/24
```

> This runs Nmap and auto-imports the results into your **active MSF workspace**.

---

## 🔎 Post-Scan Recon Commands in MSF

After import or `db_nmap` scan:

```bash
hosts         # List all discovered hosts
services      # List all services found
vulns         # (if auxiliary scans were run)
```

---

## 🧠 Pro Tips

- Always scan **from inside your workspace**.
    
- Run with `--reason` to get the logic behind port status.
    
- Combine with `nmap --script vuln` to pull CVE data.
    
- Use `-Pn` to disable ping if ICMP is blocked.
