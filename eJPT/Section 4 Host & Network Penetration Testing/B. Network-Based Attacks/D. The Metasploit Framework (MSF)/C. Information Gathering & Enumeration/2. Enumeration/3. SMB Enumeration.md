### 📁 SMB (Server Message Block) Enumeration

![[Pasted image 20250616171042.png]]

- **SMB (Server Message Block)** is an **application-layer** network protocol primarily used for:
    
    - **File sharing**
        
    - **Printer sharing**
        
    - **Inter-process communication (IPC)**
        
    - **Remote access to shared folders/devices** on LANs
        
- It’s heavily used in **Windows environments**, and is a common attack surface for lateral movement or data access.

---

### 🔌 SMB Ports & Protocols

|Version|Transport|Port|
|---|---|---|
|Legacy SMB over NetBIOS|NetBIOS over TCP/IP|**TCP 139**|
|Modern SMB|Direct over TCP/IP|**TCP 445**|

- SMB **originally ran over NetBIOS** (port 139), but modern implementations (SMBv2, SMBv3) use **port 445** directly.
    
- **NetBIOS Name Service (UDP 137)** and **NetBIOS Datagram (UDP 138)** are also part of the legacy stack.
    

---

### 🐧 SAMBA on Linux

- **SAMBA** is the **open-source** implementation of SMB for Unix/Linux systems.
    
- It allows **Linux systems to interoperate with Windows**, enabling:
    
    - Linux to share directories/printers to Windows clients
        
    - Windows clients to authenticate with Linux servers

### 🛠️ SMB Enumeration in Penetration Testing

You can use **Metasploit auxiliary modules** and other tools to:

|Objective|Example Modules / Tools|
|---|---|
|Enumerate SMB version|`auxiliary/scanner/smb/smb_version`|
|Enumerate SMB shares|`auxiliary/scanner/smb/smb_enumshares`|
|Enumerate users|`auxiliary/scanner/smb/smb_enumusers`|
|Check for null sessions (unauthenticated access)|`auxiliary/scanner/smb/smb_enum_sessions`|
|Brute-force credentials|`auxiliary/scanner/smb/smb_login`|

> **Null Sessions**: SMB servers may allow access without credentials. This is a serious vulnerability if enumeration is possible unauthenticated.

---

### 💣 Real-World Exploitation Example

1. **Identify SMB service** on TCP port 445 with Nmap:
    
    ```bash
    nmap -p 445 --script smb-os-discovery,smb-enum-shares,smb-enum-users <target>
    ```
    
2. **Attempt null session**:
    
    ```bash
    smbclient -L //<target>/ -N
    ```
    
3. **Brute-force SMB credentials** using Metasploit:
    
    ```
    use auxiliary/scanner/smb/smb_login
    set RHOSTS <target>
    set USER_FILE users.txt
    set PASS_FILE passwords.txt
    run
    ```
