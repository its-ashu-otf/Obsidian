### 🌐 Web Server Enumeration

- A **web server** is software that **hosts websites and web applications**, serving content to users over the internet or intranet.
    
- It communicates with clients (typically web browsers or tools like curl) using the **HTTP/HTTPS protocols**.
    

---

### 📡 HTTP(S) Protocol Basics

|Protocol|Port|Encryption|
|---|---|---|
|HTTP (Hypertext Transfer Protocol)|**TCP 80**|❌ No|
|HTTPS (HTTP Secure)|**TCP 443**|✅ Yes (SSL/TLS)|

- **HTTP** operates at the **Application Layer (Layer 7)** of the OSI model.
    
- It's a **stateless protocol**, meaning each request is independent.
    
- HTTPS uses **SSL/TLS** to encrypt traffic — critical for protecting credentials and sensitive data.
    

---

### 🛠️ Web Server Enumeration Goals

In penetration testing, web server enumeration helps you:

1. **Identify the web server type and version**
    
2. **Extract HTTP headers** (may expose software, OS info, or cookies)
    
3. **Discover directories/files (forced browsing)**
    
4. **Find virtual hosts or subdomains**
    
5. **Enumerate technologies/frameworks in use**

### 🔍 Enumeration Tools (Beyond Metasploit)

- `nmap` with NSE scripts:
    
    ```bash
    nmap -p 80,443 --script http-* <target>
    ```
    
- `dirb`, `gobuster`, `feroxbuster` — for brute-forcing directories
    
- `whatweb`, `wappalyzer`, `webanalyze` — for fingerprinting technologies
    
- `curl -I <url>` — to fetch HTTP headers
    
- `nikto` — for known vulnerabilities and misconfig detection
    

---

### ⚠️ Real-World Pentest Tip

Look out for:

- **Exposed admin panels** (`/admin`, `/login`)
    
- **Backup files** (`.bak`, `.zip`, `.old`)
    
- **Verbose error messages**
    
- **Outdated server versions** with known CVEs
