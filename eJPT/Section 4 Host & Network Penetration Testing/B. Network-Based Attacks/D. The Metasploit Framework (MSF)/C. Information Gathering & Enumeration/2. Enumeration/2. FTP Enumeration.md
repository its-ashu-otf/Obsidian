### 🗂️ FTP (File Transfer Protocol) Overview

- **FTP (File Transfer Protocol)** is a standard network protocol used for transferring files between a client and server.
    
- It operates over **TCP port 21** (control connection), while data transfer typically uses **TCP port 20** or dynamically assigned ports depending on **active** or **passive** mode.
    
- FTP is often used to upload/download files to/from **web servers** or **internal file repositories**, making it a common target during penetration testing.
    

---

### ⚙️ FTP in Penetration Testing

- Several **Metasploit auxiliary modules** are available to:
    
    - **Enumerate FTP servers** (e.g., banner grabbing, version detection)
        
    - **Check for anonymous login access**
        
    - **Brute-force credentials** using known username/password lists
        
- These modules help uncover **misconfigurations** or **weak authentication mechanisms**, which may lead to unauthorized access.
    

---

### 🔐 FTP Authentication & Anonymous Access

- FTP typically uses a **username:password** authentication mechanism.
    
- **Anonymous FTP login** is sometimes enabled for public access, usually with:
    
    ```
    Username: anonymous
    Password: <any or email>
    ```
    
    > This is often misconfigured to allow **write** access, posing a serious security risk.
    
- If anonymous login is allowed, it can be used to enumerate directory structures, download sensitive files, or even upload malicious files (in rare, poorly secured cases).
