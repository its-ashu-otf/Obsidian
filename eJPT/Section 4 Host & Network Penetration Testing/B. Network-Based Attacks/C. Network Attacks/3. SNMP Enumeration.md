### 🔧 **Simple Network Management Protocol (SNMP) Overview**

**Purpose**:  
SNMP is used to **monitor, manage, and configure** network devices like routers, switches, servers, etc.

**Protocol Layer**:  
Application Layer (uses UDP)

**Default Ports**:

- **UDP 161** – SNMP queries (polling)
    
- **UDP 162** – SNMP traps (asynchronous alerts)
    

---

### ⚙️ **Core Components**

|Component|Function|
|---|---|
|**SNMP Manager**|Queries devices and collects data|
|**SNMP Agent**|Resides on the device and responds to manager queries|
|**MIB (Management Information Base)**|Database of managed objects, accessed via OIDs (Object Identifiers)|

---

### 🔐 **SNMP Versions**

|Version|Auth Method|Security Features|
|---|---|---|
|SNMPv1|Community Strings|No encryption, minimal security|
|SNMPv2c|Community Strings|Bulk transfers, still no encryption|
|SNMPv3|User-based Auth|Encryption, integrity, and authentication|

### 🛠️ **SNMP Enumeration Goals (For Pentesters)**

1. **Discover SNMP-Enabled Hosts**
    
    - Use tools like `onesixtyone`, `snmpwalk`, or `nmap -sU -p 161 --script=snmp-*`
        
2. **Extract System Info**
    
    - OS, hostname, location, device uptime
        
    - Example: `snmpwalk -v2c -c public <target_ip>`
        
3. **Dump Network Config**
    
    - Interfaces, IPs, routing tables
        
    - OIDs: `1.3.6.1.2.1.4.21` (Routing table), `1.3.6.1.2.1.2` (Interfaces)
        
4. **Find Weak/Default Community Strings**
    
    - Common strings: `public`, `private`, `admin`
        
    - Bruteforce with `snmpcheck` or `onesixtyone`
        
5. **List Users & Groups**
    
    - Some devices expose local users via SNMP
        
    - OID example: `1.3.6.1.4.1.77.1.2.25` (Windows user list)
        
6. **Identify Services/Applications**
    
    - Look for running services or software versions that could have known exploits.
        

---

### 🔍 **Common SNMP Enumeration Tools**

|Tool|Purpose|
|---|---|
|`snmpwalk`|Recursively walks through MIB tree|
|`snmpget`|Gets specific OID value|
|`snmpcheck`|Performs enumeration and brute force|
|`onesixtyone`|Fast community string brute-forcing|
|`nmap`|Use NSE scripts: `snmp-*` scripts for probing|

---

### 🔥 **Attack Surface from SNMP Misconfigurations**

- **Default or weak community strings = read access** to sensitive info
    
- **RW (read-write) community strings** can allow **device reconfiguration**
    
- Exposure of **usernames**, **network topologies**, **routing info**
    
- Possible **privilege escalation** or **pivot points**
