## 🔥 PART 1: Firewall Detection using Nmap

### 🎯 Objective:

Identify if there's a firewall, what it's filtering, and how it's behaving (stateful, stateless, etc.).

---

### 🔎 1. **TCP ACK Scan (`-sA`)**

Used to determine whether a firewall is **stateful or stateless**.

```bash
nmap -sA <target>
```

📌 **Explanation**:

- Sends **ACK packets**.
    
- If **no response**, port is **filtered** (likely dropped by a firewall).
    
- If **RST response**, port is **unfiltered** (no stateful inspection).
    

---

### 🔥 2. **TCP NULL Scan (`-sN`)**, **FIN Scan (`-sF`)**, **XMAS Scan (`-sX`)**

```bash
nmap -sN <target>
nmap -sF <target>
nmap -sX <target>
```

📌 **Explanation**:

- These send **non-standard TCP flags**.
    
- Some firewalls (especially older ones) **don't block** these properly.
    
- If open/closed can't be determined, port is likely **filtered**.
    

---

### 🛡️ 3. **Firewall Rule Detection via IP ID (`--ip-id-seq`)**

```bash
nmap --ip-id-seq <target>
```

📌 **Explanation**:

- Analyzes IP ID generation patterns.
    
- Non-sequential IDs may suggest **packet filtering** or NAT/firewall tampering.

## 👁️ PART 2: IDS/IPS Evasion using Nmap

### 🧠 Goal:

Avoid detection/logging by intrusion detection/prevention systems (e.g., Snort, Suricata, Cisco ASA, etc.)

---

### ⚙️ 1. **Fragment Packets (`-f`)**

```bash
nmap -f <target>
```

📌 **Explanation**:

- Breaks packets into **tiny fragments**.
    
- Evades deep packet inspection by splitting payload.
    

🧪 **Variant**:

```bash
nmap -f -p 80 --script=http-title <target>
```

---

### 🛠️ 2. **Change MTU Size (`--mtu`)**

```bash
nmap --mtu 24 <target>
```

📌 **Explanation**:

- Alters the size of packets to **bypass pattern-based detection**.
    
- Best when combined with `-f`.
    

---

### 🎭 3. **Decoy Scan (`-D`)**

```bash
nmap -D RND:10 <target>
```

📌 **Explanation**:

- Spoofs multiple IPs as decoys.
    
- Real IP gets buried in a crowd.
    

🧪 Or manually:

```bash
nmap -D 192.168.1.10,192.168.1.11,ME,192.168.1.12 <target>
```

---

### 🕵️ 4. **Spoof Source IP (`-S`)** + Interface (`-e`)

_(Works best in spoofable test environments)_

```bash
nmap -S <spoofed_IP> -e <interface> <target>
```

📌 **Explanation**:

- Sends packets with **spoofed source IP**.
    
- Won’t get responses (since they go to the spoofed IP), but useful for causing confusion or testing firewall rules.
    

---

### ⏱️ 5. **Timing Templates (`-T0` to `-T5`)**

```bash
nmap -T0 <target>
```

📌 **Explanation**:

- `-T0` is **Paranoid** (very slow, stealthy).
    
- `-T5` is **Insane** (fast, aggressive).
    
- Lower values evade rate-based IDS detection.
    

---

### 🎲 6. **Randomize Scan Order (`--randomize-hosts`, `--badsum`)**

```bash
nmap --randomize-hosts -iL targets.txt
nmap --badsum <target>
```

📌 **Explanation**:

- `--badsum` sends **malformed checksums**. Real machines won’t reply, but IDS might log it.
    

---

### 🧩 7. **Using Custom Data (`--data-length`)**

```bash
nmap --data-length 100 <target>
```

📌 **Explanation**:

- Pads packets with **random data**.
    
- Obscures the payload from pattern detection.
    

---

### 🐌 8. **Idle/Zombie Scan (`-sI`)**

```bash
nmap -sI <zombie_IP> <target>
```

📌 **Explanation**:

- Scan using a third-party host with predictable IP ID (zombie).
    
- No direct connection between attacker and target = ultra stealth.

## 📋 Nmap Firewall & IDS Evasion Cheat Sheet

|Purpose|Command|Notes|
|---|---|---|
|Detect firewall (stateful)|`nmap -sA <target>`|ACK scan|
|Detect firewall filtering|`nmap -sN / -sF / -sX <target>`|Stealthy TCP flag tricks|
|Evasion via fragmentation|`nmap -f <target>`|Splits into small IP fragments|
|Change MTU|`nmap --mtu 24 <target>`|Obfuscates payload|
|Decoy scan|`nmap -D RND:10 <target>`|Spoofs 10 random decoys|
|IP spoofing|`nmap -S <spoofed_IP> -e eth0 <target>`|No replies, stealth only|
|Stealthy timing|`nmap -T0 <target>`|Avoids triggering IDS|
|Add junk data|`nmap --data-length 100 <target>`|Obfuscates signature|
|Malformed checksum|`nmap --badsum <target>`|No real replies; IDS test|
|Idle zombie scan|`nmap -sI zombie_IP <target>`|Indirect scanning|
|Randomize hosts|`nmap --randomize-hosts -iL file.txt`|Confuses detection|

---

## 🛠️ Pro Tips

- Combine evasion flags smartly:
    

```bash
nmap -f --data-length 50 -T1 -D RND:5 -Pn <target>
```

- Always test in a **controlled lab** before trying these on real-world targets.
    
- Use **Wireshark or tcpdump** to see how packets look on wire.
    
- IDS like **Snort** can be used alongside your lab to study detection/evasion interplay.
