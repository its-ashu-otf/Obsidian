## 🧠 Course Overview

This course is designed to enhance your practical skills in offensive security by covering critical stages of a penetration test. You'll move from reconnaissance to exploitation and post-exploitation on both Windows and Linux systems.

---

### 🔍 Topics Covered

1. **Host Discovery & Port Scanning**
    
    - Identify active hosts on a network using various techniques on both Windows and Linux.
        
    - Use tools like Nmap and Masscan to discover open ports and associated services.
        
2. **Service Enumeration**
    
    - Extract critical information from services running on target systems.
        
    - Use Nmap scripts and protocol-specific tools to enumerate services such as SMB, NetBIOS, SMTP, FTP, etc.
        
3. **MITM & Network-Based Attacks**
    
    - Perform ARP Spoofing, DNS Spoofing, ARP Poisoning, and NBT-NS Poisoning.
        
    - Utilize tools like `arpspoof`, `dnsspoof`, and `Responder` to launch effective Man-in-the-Middle attacks.
        
4. **Windows & Linux Exploitation & Post-Exploitation**
    
    - Exploit OS-specific services and protocols (e.g., SMB, RDP, WinRM) to gain initial access.
        
    - Carry out advanced exploitation techniques such as SMB Relaying.
        
    - Conduct post-exploitation activities like privilege escalation, credential dumping, and persistence on both platforms.
        

---

## ✅ Prerequisites

To succeed in this course, you should have:

### Networking Knowledge

- Understanding of IP addressing, subnetting, routing, and core network devices (switches, routers, firewalls).
    
- Familiarity with common protocols: TCP, UDP, HTTP, DNS, etc.
    

### Operating Systems Fundamentals

- Basic proficiency with Windows and Linux, especially using their command-line interfaces.
    
- Understanding of system processes, file systems, and permission models.
    

### Exploitation & Post-Exploitation Experience

- Hands-on experience targeting and exploiting services like SMB, RDP, WinRM, etc.
    
- Ability to identify and leverage vulnerabilities/misconfigurations in Windows and Linux environments.
    

### Penetration Testing Tools & Methodology

- Familiarity with tools such as Metasploit, Nmap, and Wireshark.
    
- Understanding of standard penetration testing methodologies and frameworks.
