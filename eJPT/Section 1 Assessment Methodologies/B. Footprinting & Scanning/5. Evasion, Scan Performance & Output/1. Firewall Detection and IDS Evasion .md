### 🔥 Firewall Detection

When you’re attacking or testing a network, you first want to know:  
**"Is there a firewall?"** If yes, **"What kind?"**, **"What rules?"**

Some ways to detect a firewall:

- **TTL (Time To Live) Analysis:**
    
    - Firewalls sometimes decrement the TTL differently.
        
    - Compare TTL values in responses; weird jumps might suggest filtering.
        
- **TCP Flags/Response Behavior:**
    
    - Send strange packets (e.g., SYN + FIN) and watch how the server responds.
        
    - Firewalls often **drop** or **alter** responses for suspicious flags.
        
- **Traceroute with Different Protocols:**
    
    - Use **ICMP**, **UDP**, and **TCP** traceroutes.
        
    - If one is blocked and others succeed, it hints at firewall filtering.
        
- **Banner Grabbing:**
    
    - Some firewalls (like Palo Alto, Cisco ASA) might accidentally reveal themselves via error pages or banners.
        
- **Port Scanning Analysis:**
    
    - Ports filtered? (no response)
        
    - Ports closed? (RST response)
        
    - Open? (SYN/ACK)
        
    - A lot of "filtered" ports hint at a firewall blocking scans.
        

🛠 **Tools to help detect firewalls:**

- Nmap (`nmap -sS`, `-sA`, `-sN`, `-O`)
    
- Hping3 (custom TCP/IP packets)
    
- Firewalk (for discovering ACLs/firewall rules)

### 🕵️ IDS Evasion Techniques

**Intrusion Detection Systems (IDS)** watch for malicious traffic.  
If you want to "sneak" past them during a pentest, here are common techniques:

- **Fragmentation:**
    
    - Split attack payloads into small packets.
        
    - Some IDS struggle to reconstruct fragmented traffic.
        
    - Example: `nmap -f` (fragment packets)
        
- **Polymorphic Shellcode:**
    
    - Make your payload look different every time (but still works).
        
    - Harder for signature-based IDS to detect.
        
- **Encoding Payloads:**
    
    - Base64, URL encoding, double URL encoding...
        
    - Example: `/admin%2Flogin` instead of `/admin/login`.
        
- **Timing/Slow Attacks (Low and Slow):**
    
    - Send data very slowly to avoid threshold-based detection.
        
    - Example: Sleep 10 seconds between sending packets.
        
- **Obfuscation:**
    
    - Break attack strings across different requests.
        
    - Ex: Instead of sending `UNION SELECT username, password`, split into multiple packets.
        
- **Using Alternate Data Streams (Windows):**
    
    - Hide payloads in places the IDS might not check directly.
        
- **Custom Protocols / Encryption:**
    
    - Using SSL/TLS tunnels, SSH tunnels, or custom protocols to hide payloads.
        

🛠 **Tools for evasion practice:**

- Metasploit (payload encoding: `msfvenom`)
    
- Scapy (crafting custom packets)
    
- Hping3 (fragmentation and manipulation)

### ⚡ Quick Real-World Example

- Suppose you want to run a port scan through a firewall:
    
    - Use **Nmap Idle Scan** (`nmap -sI`) to hide yourself.
        
    - Or fragment packets (`nmap -f`) to sneak by packet inspection firewalls.
        
    - Or slow down scanning (`--scan-delay 5s`) to avoid volume-based detection.
