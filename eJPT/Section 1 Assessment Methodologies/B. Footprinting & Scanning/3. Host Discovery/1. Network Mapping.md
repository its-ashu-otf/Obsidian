### 🔍 What is Network Mapping in Penetration Testing?

**Network Mapping** is the process of identifying and visualizing all active devices, their interconnections, and the services running on them within a target network. It’s a critical step in the **Active Information Gathering** phase of a penetration test.

---

### ✅ **Why is Network Mapping Important?**

1. **Identifies Live Hosts:** Reveals which systems are up and reachable.
    
2. **Enumerates Open Ports & Services:** Helps determine what services may be vulnerable.
    
3. **OS & Service Fingerprinting:** Provides insight into what operating systems and applications are being used.
    
4. **Visual Network Layout:** Assists in understanding the network’s topology and trust boundaries.
    
5. **Entry Point Discovery:** Guides attackers to areas where exploitation might be most effective.
    

---

### 🛠️ **How Penetration Testers Perform Network Mapping**

#### 1. **Host Discovery (What’s online?)**

Used to identify live systems on a network.

- **Tools:** `Nmap`, `fping`, `Netdiscover`, `Masscan`
    
- **Techniques:**
    
    - ICMP Echo (Ping)
        
    - ARP requests (in LAN)
        
    - TCP SYN/ACK scanning
        
    - UDP probing
        

#### 2. **Port Scanning (What ports are open?)**

Detects open ports and the services listening on them.

- **Tools:** `Nmap`, `Masscan`, `Unicornscan`
    
- **Types of Scans:**
    
    - TCP SYN scan (`-sS`)
        
    - TCP Connect scan (`-sT`)
        
    - UDP scan (`-sU`)
        
    - Version detection (`-sV`)
        

#### 3. **OS Detection (What systems are running?)**

Fingerprinting the OS to tailor exploits accordingly.

- **Tools:** `Nmap` with `-O` flag
    
- **Techniques:**
    
    - TCP/IP stack fingerprinting
        
    - TTL values, window size, and response behavior analysis
        

#### 4. **Service Enumeration**

Interrogating open ports to identify service details.

- **Tools:** `Nmap`, `Netcat`, `Banner grabbing`, `Enum4linux`, `Nikto`, `SNMPwalk`
    
- **Focus Areas:**
    
    - Web servers, FTP, SSH, SMB, SNMP, DNS, etc.
        

---

### 📊 **Example Nmap Command for Network Mapping**

```bash
nmap -sS -sV -O -T4 -p- 192.168.1.0/24
```

**Explanation:**

- `-sS`: TCP SYN scan
    
- `-sV`: Service version detection
    
- `-O`: OS detection
    
- `-T4`: Faster timing template
    
- `-p-`: Scan all 65535 ports
    
- `192.168.1.0/24`: Target subnet
    

---

### 🧠 Summary

Network mapping allows penetration testers to **discover, understand, and strategize** around a target network's structure. It's the bridge between reconnaissance and exploitation — the better the map, the more surgical the attack path can be.

## 📌 **Example – Why Map a Network?**

### 🧠 **Scenario:**

A company has hired you to perform a **penetration test** on their infrastructure. The **target IP address block** provided as in-scope is:

```
200.200.0.0/16
```

### 🧮 **Understanding the Scope:**

- A `/16` CIDR block (also known as a **Class B** network) includes **65,536 possible IP addresses**.
    
- IP range: `200.200.0.0` → `200.200.255.255`
    
- Your **first job** as a penetration tester is to:
    
    1. **Identify which IPs are assigned** to hosts.
        
    2. **Determine which of those hosts are online (alive).**
        

---

### 🎯 **Objective of Network Mapping:**

When starting with zero knowledge about the internal structure of a remote network, **network mapping** helps answer:

- How many systems are there?
    
- Which IPs are active?
    
- What services or roles might these systems serve (e.g., web servers, mail servers, databases)?
    
- What does the overall **network architecture** look like?
    

---

### 🛰️ **Why It Matters:**

🔍 Without knowing which IPs are active or what devices are running, an attacker (or tester) is flying blind.

📡 Network mapping turns a **massive, unknown IP block** into a clear view of:

- **Live hosts**
    
- **Open ports & running services**
    
- **Operating systems**
    
- **Device types (e.g., routers, firewalls, printers, workstations, servers)**

## 🎯 **Network Mapping Objectives in Penetration Testing**

Network mapping provides vital insight into the structure, systems, and defenses of a target environment. Here’s what a penetration tester aims to accomplish during this phase:

---

### 1. 🟢 **Discovery of Live Hosts**

- **Goal:** Identify which IP addresses in the target range are currently active and responsive.
    
- **Why it matters:** Pinpoints the actual systems to investigate further; narrows down the focus from potentially thousands of IPs.
    

---

### 2. 🔓 **Identification of Open Ports & Services**

- **Goal:** Detect open TCP/UDP ports and identify the services running on them (e.g., HTTP, FTP, SSH).
    
- **Why it matters:** Reveals the **attack surface**—the exposed services that could be targeted for vulnerabilities or misconfigurations.
    

---

### 3. 🗺️ **Network Topology Mapping**

- **Goal:** Understand the layout of the network, including key infrastructure devices like:
    
    - Routers
        
    - Switches
        
    - Firewalls
        
    - Gateways
        
- **Why it matters:** Helps determine network segmentation, trust boundaries, and how traffic flows—key for lateral movement and pivoting.
    

---

### 4. 💻 **Operating System Fingerprinting**

- **Goal:** Identify the OS running on discovered hosts (e.g., Windows, Linux, macOS).
    
- **Why it matters:** Different OS versions have different vulnerabilities. Tailoring attacks to the correct OS increases success rates.
    

---

### 5. 🔍 **Service Version Detection**

- **Goal:** Detect the specific versions of services (e.g., Apache 2.4.49, OpenSSH 7.6p1).
    
- **Why it matters:** Some exploits are **version-specific**. Knowing exact versions helps pinpoint known vulnerabilities (CVEs).
    

---

### 6. 🔐 **Identifying Filtering & Security Measures**

- **Goal:** Detect security controls such as:
    
    - Firewalls
        
    - IDS/IPS systems
        
    - Port filtering and rate limiting
        
- **Why it matters:** Helps a pentester **adapt their approach** to avoid detection or bypass defenses (e.g., using slower scans or evasion techniques).
    

---

### 🧰 **Tools Commonly Used**

## 🧰 **Nmap (Network Mapper)**

### 🔹 **What is Nmap?**

**Nmap** is an open-source network scanning and reconnaissance tool widely used by:

- Penetration testers
    
- Security professionals
    
- Network administrators
    

It allows users to **discover hosts, services, open ports, operating systems, and vulnerabilities** on a network.

---

### 🌐 **Primary Uses of Nmap:**

1. **Host Discovery:** Identifying active/live systems in a target network.
    
2. **Port Scanning:** Detecting open TCP/UDP ports on discovered hosts.
    
3. **Service Detection:** Determining what services (and their versions) are running on open ports.
    
4. **OS Fingerprinting:** Identifying the operating system and kernel version of the target.
    
5. **Vulnerability Detection:** Using Nmap scripts (NSE) to detect misconfigurations and known vulnerabilities.
    
6. **Network Inventory:** Creating a detailed map of the target network.
    
7. **Firewall & IDS/IPS Evasion:** Techniques to bypass or test filtering mechanisms.
    

---

### ⚙️ **Key Features of Nmap:**

|Feature|Description|
|---|---|
|`-sS`|TCP SYN (Stealth) scan (default and most popular)|
|`-sT`|TCP Connect scan (full 3-way handshake)|
|`-sU`|UDP scan (for discovering UDP-based services)|
|`-sV`|Service version detection|
|`-O`|OS detection|
|`-p-`|Scan all 65,535 ports|
|`-A`|Aggressive scan (includes `-sV`, `-O`, script scanning, and traceroute)|
|`-T<0-5>`|Timing template (`-T4` is fast and stable for most networks)|
|`-Pn`|Skip host discovery (assume all hosts are up)|
|`-sn`|Ping scan only (no port scan)|

---

### 🧠 **Nmap Scripting Engine (NSE):**

- Allows automation of advanced network discovery and vulnerability detection.
    
- Scripts are categorized into:
    
    - **Auth**, **Default**, **Discovery**, **Exploit**, **External**, **Malware**, **Vuln**, etc.
        
- Example:
    
    ```bash
    nmap --script vuln 192.168.1.10
    ```
    

---

### 🧪 **Example Nmap Command:**

```bash
nmap -sS -sV -O -p- -T4 192.168.1.0/24
```

**Explanation:**

- `-sS`: SYN scan
    
- `-sV`: Detect service versions
    
- `-O`: OS fingerprinting
    
- `-p-`: Scan all ports
    
- `-T4`: Use faster timing
    
- `192.168.1.0/24`: Target subnet
    

---

### 💡 **Why Nmap is Essential in Pentesting:**

- Rapid network enumeration
    
- Customizable and scriptable
    
- Active community and robust documentation
    
- Works across platforms (Linux, Windows, macOS)

## ⚙️ Nmap Functionality

Nmap offers a wide range of capabilities that make it a powerful tool for both reconnaissance and vulnerability assessment. Below are its core functionalities:

---

### 1. 🟢 **Host Discovery**

- **Purpose:** Identify which hosts are **online** and reachable on a given network.
    
- **Techniques Used:**
    
    - **ICMP Echo Requests** (like `ping`)
        
    - **ARP Requests** (within local networks)
        
    - **TCP SYN/ACK Probes**
        
    - **UDP Probes**
        
- **Command Example:**
    
    ```bash
    nmap -sn 192.168.1.0/24
    ```
    
    _(Performs a ping scan to discover live hosts without port scanning)_
    

---

### 2. 🔓 **Port Scanning**

- **Purpose:** Determine which **TCP or UDP ports** are open on the target systems.
    
- **Types of Scans:**
    
    - `-sS`: SYN (stealth) scan
        
    - `-sT`: TCP connect scan
        
    - `-sU`: UDP scan
        
    - `-sN`, `-sF`, `-sX`: NULL, FIN, and Xmas scans (firewall evasion)
        
- **Command Example:**
    
    ```bash
    nmap -sS -p 1-1000 192.168.1.10
    ```
    

---

### 3. 🔍 **Service Version Detection**

- **Purpose:** Identify the **software and version** running on each open port.
    
- **Why It Matters:** Certain exploits target specific service versions.
    
- **Command Example:**
    
    ```bash
    nmap -sV 192.168.1.10
    ```
    
    _(Detects services and their versions on open ports)_
    

---

### 4. 💻 **Operating System Fingerprinting**

- **Purpose:** Identify the **operating system and kernel version** running on the target.
    
- **Technique:** Uses TCP/IP stack fingerprinting, TTL, window size, and response behavior.
    
- **Command Example:**
    
    ```bash
    nmap -O 192.168.1.10
    ```
    
    _(Attempts to detect the OS type and version)_
    

---

### 🔄 **Combining Functionalities**

Nmap allows combining multiple scans in a single command:

```bash
nmap -sS -sV -O -p- -T4 192.168.1.10
```

- SYN scan
    
- Service/version detection
    
- OS fingerprinting
    
- All ports
    
- Faster timing
