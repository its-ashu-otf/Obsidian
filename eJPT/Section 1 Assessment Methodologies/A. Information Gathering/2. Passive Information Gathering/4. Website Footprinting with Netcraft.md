Netcraft (netcraft.com) is a tool for passive website footprinting. Enter a domain into its Site Report feature, and it pulls public data like:
- IP address
- Web server (e.g., Apache, Nginx)
- OS (guessed, e.g., Linux)
- Hosting provider (e.g., AWS)
- WHOIS details (if available)
- SSL info
- Hosting history

**Use**: Stealthy recon for cybersecurity or research—maps a site’s infrastructure without direct contact.  
**Limits**: CDNs or privacy services can hide details; no real-time probing.  
**Example**: `tesla.com` might show Akamai hosting, Linux OS, and an IP like `104.98.112.153`.
