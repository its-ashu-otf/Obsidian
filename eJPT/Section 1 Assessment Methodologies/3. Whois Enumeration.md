A WHOIS tool is a utility—either a command-line program, a web-based interface, or a software application—that allows you to query the WHOIS database to retrieve information about a domain name, IP address, or autonomous system number (ASN). These tools connect to WHOIS servers maintained by registrars or organizations like ICANN, ARIN, or RIPE to fetch details such as:

- Domain registrant (owner) name and contact info (if not privacy-protected)
- Registration and expiration dates
- Name servers
- Registrar details

### Examples of WHOIS Tools:
1. **Command-Line Tools**:
   - On Unix/Linux/macOS: `whois example.com` (built into most systems).
   - On Windows: You’d need a third-party tool like `whoiscl` or a PowerShell script since it’s not native.

2. **Web-Based Tools**:
   - Sites like `whois.domaintools.com`, `whois.net`, or `lookup.icann.org` let you enter a domain and get results instantly.

3. **Specialized Software**:
   - Tools like Nmap or Recon-ng (used in cybersecurity) can integrate WHOIS queries for enumeration during network reconnaissance.

### How to Use a Basic WHOIS Tool:
- **Command Line**: Open a terminal and type `whois google.com`. You’ll get a raw output with registration details.
- **Online**: Visit a site like `whois.icann.org`, input a domain, and review the formatted results.
