Subdomain enumeration is the process of identifying valid subdomains associated with a target domain (e.g., discovering `app.example.com` or `dev.example.com` for `example.com`). It’s commonly used in cybersecurity to map a domain’s attack surface, uncover hidden servers, or find potential vulnerabilities.

### How It Works
- **Passive Methods**: Collect subdomains from public sources like DNS records, certificate transparency logs (e.g., crt.sh), or search engines without directly interacting with the target.
- **Active Methods**: Query the domain using tools to brute-force or guess subdomains (e.g., trying `mail`, `test`, etc.) via DNS lookups or HTTP requests.
- **Hybrid**: Combine both for broader coverage.

### Purpose
- **Security Testing**: Find unmonitored or misconfigured subdomains.
- **Reconnaissance**: Gather info for penetration testing or bug bounties.
- **Defense**: Identify subdomains an attacker might exploit.

In short, it’s about systematically uncovering all subdomains tied to a domain to understand its digital footprint.
