Subdomain enumeration is the process of identifying valid subdomains associated with a target domain (e.g., discovering `app.example.com` or `dev.example.com` for `example.com`). It’s commonly used in cybersecurity to map a domain’s attack surface, uncover hidden servers, or find potential vulnerabilities.

### How It Works
- **Passive Methods**: Collect subdomains from public sources like DNS records, certificate transparency logs (e.g., crt.sh), or search engines without directly interacting with the target.
- **Active Methods**: Query the domain using tools to brute-force or guess subdomains (e.g., trying `mail`, `test`, etc.) via DNS lookups or HTTP requests.
- **Hybrid**: Combine both for broader coverage.

### Purpose
- **Security Testing**: Find unmonitored or misconfigured subdomains.
- **Reconnaissance**: Gather info for penetration testing or bug bounties.
- **Defense**: Identify subdomains an attacker might exploit.

In short, it’s about systematically uncovering all subdomains tied to a domain to understand its digital footprint.

### Usage

| Short Form | Long Form       | Description                                          |
|------------|-----------------|------------------------------------------------------|
| `-d`       | `--domain`      | Domain name to enumerate subdomains of              |
| `-b`       | `--bruteforce`  | Enable the subbrute bruteforce module               |
| `-p`       | `--ports`       | Scan found subdomains against specific TCP ports    |
| `-v`       | `--verbose`     | Enable verbose mode and display results in real-time|
| `-t`       | `--threads`     | Number of threads for subbrute bruteforce           |
| `-e`       | `--engines`     | Specify a comma-separated list of search engines    |
| `-o`       | `--output`      | Save results to a text file                         |
| `-h`       | `--help`        | Show the help message and exit                      |


Examples

To list all the basic options and switches use *-h* switch:

```bash
sublist3r.py -h
```


To enumerate subdomains of specific domain:

```bash
 sublist3r.py -d example.com
```

To enumerate subdomains of specific domain and show only subdomains which have open ports 80 and 443 :

```bash
sublist3r.py -d example.com -p 80,443
```

To enumerate subdomains of specific domain and show the results in real-time:

```bash
sublist3r.py -v -d example.com
```

To enumerate subdomains and enable the brute force module:

```bash
sublist3r.py -b -d example.com
```

To enumerate subdomains and use specific engines such Google, Yahoo and Virus total engines

```bash
sublist3r.py -e google,yahoo,virustotal -d example.com
```
