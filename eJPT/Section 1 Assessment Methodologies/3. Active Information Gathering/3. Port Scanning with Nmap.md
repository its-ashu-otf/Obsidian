## 🔍 What is Port Scanning?

Port scanning is the process of sending packets to specific ports on a host and analysing the responses to learn:

- Which ports are **open**, **closed**, or **filtered**
    
- What services are running
    
- The versions of services
    
- Operating system and firewall behavior


---

## 🛠 Basic Nmap Syntax

```bash
nmap [options] [target]
```

Example:

```bash
nmap 192.168.1.1
```

## 🔹 What Does `-Pn` Do in Nmap?

```bash
nmap -Pn [target]
```
``
### ✅ It **skips host discovery** (ping).

By default, Nmap pings the target first to check if it’s "alive" (using ICMP, TCP ACK, or SYN packets). If it gets no response, Nmap **skips** scanning that host.

With `-Pn`, Nmap **assumes the host is up** and proceeds with the scan.

---

## 🧠 When to Use `-Pn`?

- 🔐 The target has a **firewall** that blocks ICMP or ping responses.
    
- 🕵️‍♂️ You're scanning an **external IP** (e.g., on the internet) and not getting responses.
    
- 👻 You want to **bypass detection** or scan **quietly**.
    
- 🔬 In a **CTF or lab**, where targets may ignore ping.
    

---
## ⚠️ Caution

Using `-Pn` on large networks can waste time scanning hosts that are actually **offline**, since Nmap will still try all ports.

## 🔹 Common Scan Types

### 1. **TCP Connect Scan** (Full 3-way handshake)

```bash
nmap -sT 192.168.1.1
```

- Easy to detect
    
- Doesn’t require root privileges
    

---

### 2. **SYN Scan** (Stealth Scan)

```bash
nmap -sS 192.168.1.1
```

- Most popular
    
- Faster and stealthier
    
- Requires root/admin privileges
    

---

### 3. **UDP Scan**

```bash
nmap -sU 192.168.1.1
```

- Slower and harder to interpret
    
- Useful for detecting DNS, SNMP, etc.
    

---

### 4. **Scan Multiple Targets**

```bash
nmap 192.168.1.1 192.168.1.2
nmap 192.168.1.0/24
```

---

## 🔍 Service and Version Detection

```bash
nmap -sV 192.168.1.1
```

- Attempts to identify service versions on open ports
    

---

## 📜 OS Detection

```bash
nmap -O 192.168.1.1
```

- OS fingerprinting using TCP/IP stack analysis
    

---

## 🔥 Aggressive Scan

```bash
nmap -A 192.168.1.1
```

- Enables: OS detection, version detection, script scanning, traceroute
    
- Noisy, but detailed
    

---

## 🧠 Top 100/1000 Ports Scan

```bash
nmap --top-ports 100 192.168.1.1
```

---

## ⚡ Fast Scan (No DNS, fewer ports)

```bash
nmap -F 192.168.1.1
```

---

## 📜 Output Options

- Normal output: `-oN`
    
- XML output: `-oX`
    
- Grepable output: `-oG`
    
- All at once:
    

```bash
nmap -A 192.168.1.1 -oA scan_results
```

---

## 🔒 Evading Firewalls / IDS

- Fragment packets:
    
    ```bash
    nmap -f 192.168.1.1
    ```
    
- Randomize scan:
    
    ```bash
    nmap -T2 192.168.1.1
    ```
    
- Use decoys:
    
    ```bash
    nmap -D RND:10 192.168.1.1
    ```
    
- Spoof MAC:
    
    ```bash
    nmap --spoof-mac Apple 192.168.1.1
    ```
    

---

## ⚙️ Scan with Scripts (NSE)

```bash
nmap --script vuln 192.168.1.1
```

- Runs vulnerability detection scripts
    
- Use `--script-help=default` to explore

# 🧠 Nmap Port Scanning Cheat Sheet

---

## 🔹 Basic Scans

|Description|Command|
|---|---|
|TCP Connect Scan|`nmap -sT target`|
|SYN (Stealth) Scan|`nmap -sS target`|
|UDP Scan|`nmap -sU target`|
|Specific Port|`nmap -p 80 target`|
|Port Range|`nmap -p 1-1000 target`|
|All Ports (1–65535)|`nmap -p- target`|
|Top 100 Ports|`nmap --top-ports 100 target`|
|Fast Scan|`nmap -F target`|

---

## 🔹 Discovery & Detection

|Description|Command|
|---|---|
|Skip Ping (treat as up)|`nmap -Pn target`|
|OS Detection|`nmap -O target`|
|Version Detection|`nmap -sV target`|
|Aggressive Scan|`nmap -A target`|
|Traceroute|`nmap --traceroute target`|

---

## 🔹 Timing & Performance

|Description|Command|
|---|---|
|Set Timing Template|`nmap -T[0-5] target`|
|Example (aggressive)|`nmap -T4 target`|

---

## 🔹 Stealth / Evasion

|Description|Command|
|---|---|
|Fragment Packets|`nmap -f target`|
|Decoy Scan|`nmap -D RND:10 target`|
|Spoof MAC Address|`nmap --spoof-mac Apple target`|
|Idle Scan|`nmap -sI zombie_ip target`|
|Disable DNS Resolution|`nmap -n target`|

---

## 🔹 Script Engine (NSE)

|Description|Command|
|---|---|
|Default Scripts|`nmap -sC target`|
|Vulnerability Scan|`nmap --script vuln target`|
|Specific Script|`nmap --script http-title target`|
|Script Help|`nmap --script-help http-title`|

---

## 🔹 Output Options

|Description|Command|
|---|---|
|Normal Output|`nmap -oN scan.txt target`|
|Grepable Output|`nmap -oG scan.gnmap target`|
|XML Output|`nmap -oX scan.xml target`|
|All Formats|`nmap -oA all_outputs target`|

---

## 🔹 Multiple Targets

|Description|Command|
|---|---|
|Range|`nmap 192.168.1.1-50`|
|Subnet (CIDR)|`nmap 192.168.1.0/24`|
|Multiple IPs|`nmap 192.168.1.1 192.168.1.2`|
|From File|`nmap -iL targets.txt`|

---

## 🔹 Useful Combos

```bash
# Aggressive scan with all outputs and no ping
nmap -A -Pn -oA scan 192.168.1.100

# Full TCP + UDP port scan
nmap -sS -sU -p- 192.168.1.100

# Stealthy scan with decoys and spoofed MAC
nmap -sS -D RND:5 --spoof-mac 0 192.168.1.100
```
