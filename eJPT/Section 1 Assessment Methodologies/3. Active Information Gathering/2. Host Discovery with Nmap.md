 **Host discovery** is the first step in network reconnaissance — it helps identify **live devices** on a network before scanning ports or services.


---

# 🌐 Host Discovery with **Nmap** and **Netdiscover**

---

## 🔍 1. **Nmap** – Network Mapper

Nmap is a powerful tool that can discover hosts **by sending packets and analyzing responses**.

### ✅ Basic Host Discovery Command:

```bash
nmap -sn 192.168.1.0/24
```

This tells Nmap to:

- **`-sn`**: Ping scan (host discovery only — no port scan)
    
- **`192.168.1.0/24`**: Target subnet

### 🔧 Advanced Host Discovery:

|Option|Description|
|---|---|
|`-Pn`|Skip ping (useful for firewalled hosts)|
|`-PS`|TCP SYN ping|
|`-PA`|TCP ACK ping|
|`-PE`, `-PP`, `-PM`|ICMP Echo, Timestamp, Netmask|
|`--disable-arp-ping`|Turn off ARP (layer 2) ping|
|`--reason`|Show why a host is up|

#### Example with multiple discovery methods:

```bash
nmap -PE -PS80,443 -PA21,23 -sn 192.168.1.0/24
```

## 🖥️ 2. **Netdiscover** – ARP-based Host Discovery

`netdiscover` is great for **LAN scanning**, especially in internal networks where ARP is effective.

### ✅ Scan Entire Subnet:

```bash
sudo netdiscover -r 192.168.1.0/24
```

- **`-r`**: Range to scan
    
- Uses **ARP requests** to find live hosts and their MAC addresses
    

### 🧪 Output:

```
IP            MAC Address        Vendor             Hostname
192.168.1.1   00:11:22:33:44:55  Cisco Systems      router
192.168.1.10  aa:bb:cc:dd:ee:ff  Intel Corp         desktop
```

### 💡 Why Use Netdiscover?

- Super fast in local networks
    
- Doesn’t rely on ICMP/TCP/UDP — just **ARP**
    
- No need to guess IPs — it broadcasts to the whole subnet
    

---

## 🧠 When to Use What?

|Tool|Best For|Network Type|
|---|---|---|
|`nmap -sn`|Full-featured, scriptable scan|Any (LAN/WAN)|
|`netdiscover`|Quick live host scan via ARP|LAN/internal|

---

## 🚀 Bonus: Combine Tools in a Lab

1. Run `netdiscover` to quickly find live hosts
    
2. Take the list and feed it to Nmap for deeper scanning:
    

```bash
nmap -iL live_hosts.txt -A
```
