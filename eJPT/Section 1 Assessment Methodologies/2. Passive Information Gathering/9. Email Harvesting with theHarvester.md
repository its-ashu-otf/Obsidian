## **What is theHarvester?**

**theHarvester** is an open-source OSINT (Open Source Intelligence) tool used to gather information about a target organization, such as emails, subdomains, IPs, and employee names. It is widely used in cybersecurity for reconnaissance and footprinting.

### **Key Features of theHarvester**

- Email harvesting from various public sources
    
- Domain name and subdomain enumeration
    
- Gathering IP addresses and hostnames
    
- Integration with search engines and APIs (Google, Bing, DuckDuckGo, etc.)

###  **1. Run theHarvester to Collect Emails**

Use the following command to harvest emails from a target domain:

```bash
theHarvester -d example.com -b google
```

**Explanation:**

- `-d example.com` → Target domain
    
- `-b google` → Uses Google for searching emails
    

---

### **2. Using Multiple Sources for Better Results**

```bash
theHarvester -d example.com -b google,bing,duckduckgo
```

This command queries multiple search engines to increase the number of harvested emails.

---

### **3. Exporting the Results**

To save the results in a text file:

bash

CopyEdit

`theHarvester -d example.com -b google -f output.txt`

To export in HTML format:

bash

CopyEdit

### **Step 5: Using API Keys for More Data**

Some sources like **Google, Bing, and Hunter.io** require API keys for advanced results. You can configure them in theHarvester settings.
