# Installing GoPhish on Ubuntu

## Objective

This lab will guide you through installing GoPhish on an Ubuntu-based server and preparing it for secure access. The lab includes firewall configuration, initial system updates, downloading GoPhish, extracting the binary, modifying core configuration files, and ensuring access is properly restricted.

By the end of this lab, you will have:

- Configured firewall rules to restrict access.
- Installed required packages and updated your server.
- Downloaded and extracted the GoPhish binary.
- Modified the `config.json` to allow external access to the admin panel.
- Prepared your server for further setup, including HTTPS configuration.

---

## Step 1: Configure Firewall in DigitalOcean

1. Navigate to your droplet in the DigitalOcean Control Panel.
2. Under the left-hand navigation, select **Networking**, then **Firewalls**.
3. Open the firewall group assigned to your droplet (e.g., “My IP Only”).
4. Add a **New Rule**:

- - **Protocol**: TCP
    - **Ports**: All
    - **Sources**: Your public IP address only (you can retrieve it by running `curl ifconfig.me`).

Confirm the rule by pressing **Enter** after pasting your IP, then click **Save**.

**Why this is important**: GoPhish will expose services on ports like `3333` (admin interface) and `80` (phishing server). Restricting access to your IP protects these endpoints from external visibility during setup.

---

## Step 2: Connect to the Server via SSH

Open your terminal and connect to the droplet using SSH:

```bash
ssh root@your-droplet-ip
```

Replace `your-droplet-ip` with the actual IP of your droplet, found in the DigitalOcean dashboard.

Once connected, you are operating on the Ubuntu server in the cloud.

---

## Step 3: Update and Prepare the System

Run the following commands to update your system and install essential tools:

apt update apt upgrade apt install unzip

These steps ensure your repositories and installed packages are up to date. Installing `unzip` allows you to extract the GoPhish archive.

---

## Step 4: Download and Extract GoPhish

Create a new directory for GoPhish and move into it:

mkdir gophish cd gophish

Download the GoPhish binary using the `wget` command:

```bash
wget [https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip](https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip)
```
Extract the downloaded file:

```bash
unzip gophish-v0.12.1-linux-64bit.zip
```

Mark the GoPhish binary as executable:

```bash
chmod +x gophish
```

At this point, you should see the GoPhish binary ready to execute.

---

## Step 5: Modify Configuration for Remote Admin Access

To make the admin portal accessible externally:

Open the configuration file using the `nano` text editor:

```
nano config.json
```

Locate the line with the admin server’s `listen_url`. Change it from:

```
"listen_url": "127.0.0.1:3333"
```

to:

```
"listen_url": "0.0.0.0:3333"
```

This change allows GoPhish to accept connections on all network interfaces.

Save the file:

- Press `Ctrl + X` to exit.
- Press `Y` to confirm saving.
- Press `Enter` to overwrite the existing file.

Confirm the update was saved:

```
cat config.json
```

You should see the modified `listen_url`.
