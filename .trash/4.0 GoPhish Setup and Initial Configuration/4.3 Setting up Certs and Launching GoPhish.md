## Objective

In this lab, you will complete the configuration of your GoPhish instance by setting up a TLS/SSL certificate and launching the application. You will also log into the admin portal to verify the setup and prepare for campaign development.

By the end of this lab, you will have:

- Installed Certbot and generated an SSL certificate using DNS-based validation.
- Updated the GoPhish configuration file to enable HTTPS.
- Launched GoPhish and verified successful access to the admin interface.

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/43-setting-up-certs-and-launching-gophish#user-content-step-1-install-certbot)Step 1: Install Certbot

Certbot is used to generate an SSL certificate via Let’s Encrypt.

```
apt install certbot
```

Once installed, clear the terminal for readability.

---

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/43-setting-up-certs-and-launching-gophish#user-content-step-2-generate-the-certificate-via-dns-challenge)Step 2: Generate the Certificate via DNS Challenge

Run the following command, replacing `[your-domain]` with your actual domain name:

```
certbot certonly -d [your-domain] --manual --preferred-challenges dns --register-unsafely-without-email
```

You will be prompted to:

- Accept the Terms of Service.
- Add a DNS TXT record to your domain's DNS settings.

**Instructions**:

1. Log into your domain registrar (e.g., Namecheap).
2. Navigate to the DNS settings for your domain.
3. Add a **TXT record** with the values provided by Certbot:

- **Host**: The specific subdomain provided (usually a `_acme-challenge` string).
- **Value**: The validation token from Certbot.
- **TTL**: Set to 1 minute, if available.

After saving the DNS record, **wait at least one minute** to allow propagation, then press **Enter** in the terminal to continue.

Certbot should confirm success and show the certificate and key file paths (typically in `/etc/letsencrypt/live/[your-domain]/`). Copy and save these paths.

---

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/43-setting-up-certs-and-launching-gophish#user-content-step-3-update-configjson-with-ssl-certificate-paths)Step 3: Update `config.json` with SSL Certificate Paths

Edit the GoPhish configuration file:

```
nano config.json
```

Update the following fields with your actual cert and key paths:

```
"cert_path": "/etc/letsencrypt/live/[your-domain]/fullchain.pem", "key_path": "/etc/letsencrypt/live/[your-domain]/privkey.pem"
```

After editing, save and close the file:

- Press `Ctrl + X`
- Press `Y` to confirm
- Press `Enter` to save

Verify the update:

```
cat config.json
```

Check that the certificate and key paths match what Certbot provided.

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/43-setting-up-certs-and-launching-gophish#user-content-step-4-launch-gophish)Step 4: Launch GoPhish

Run the GoPhish binary:

```
./gophish
```

You should see log output indicating that GoPhish has started. Look for a line showing the initial login credentials. The default username is `admin`, and a temporary password will be generated.

Save this information securely.

---

## [](https://www.hacksmarter.org/courses/3f9917b1-13b0-48f4-b43f-387e245656e7/take/43-setting-up-certs-and-launching-gophish#user-content-step-5-access-the-admin-portal)Step 5: Access the Admin Portal

In your web browser, navigate to:

```
https://[your-ip]:3333
```

If you receive a browser warning about an untrusted certificate, proceed by accepting the risk (this is expected if using a self-signed or newly issued cert).

Log in using:

- **Username**: `admin`
- **Password**: Temporary password from the GoPhish launch output

You will be prompted to set a new password. Enter and confirm it to proceed.
