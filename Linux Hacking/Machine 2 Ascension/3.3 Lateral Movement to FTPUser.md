## Lateral Movement to FTPUser

---

This session focused on lateral movement to the ftpuser by brute-forcing the FTP service using a discovered password list and retrieving Flag 3.

### 1. Targeting Flag 3: The FTP User
---

The objective was to compromise the `ftpuser` to access Flag 3, which the hints stated was located in `/opt/ftpuser`.

User Check: The `/etc/passwd` file confirmed that `ftpuser` has a valid login shell.

### A. Password Spraying via FTP
Given that an initial enumeration revealed a file named `pwlist.txt` on the anonymous FTP share and we needed credentials for the `ftpuser`, a password-spraying attack was executed using Hydra.

- **Attack Command**: Hydra was run from the attacker's machine against the FTP service, targeting the username `ftpuser` and using the discovered password list.
```bash
ashu@kali ~ hydra -l ftpuser -P pwlist.txt ftp://ascension.hsm  
```

- Result: The brute-force attack quickly found a valid password.
	- Credentials: `ftpuser:secret`
